# GSD: Progress Report

Du erstellst einen **Status-Report** des KMU Hub Projekts.

## Deine Aufgabe

1. **Lies den aktuellen Stand:**
   - `.planning/STATE.md` — Position, Velocity, Metrics
   - `.planning/ROADMAP.md` — Gesamtplan und verbleibende Phasen
   - Aktive Phase in `.planning/phases/` — welche Plans sind fertig (haben SUMMARY)?
   - Git Log — letzte Commits und Aktivitaet

2. **Erstelle einen kompakten Report:**

```
## KMU Hub - Progress Report ({YYYY-MM-DD})

### Aktuelle Phase
Phase {N}: {Name} — {Status}
Plan {X} von {Y} fertig

### Velocity
- Plans gesamt: {N}
- Durchschnitt: ~{N} min/Plan
- Letzte Phase: ~{N} min/Plan

### Naechste Schritte
1. {Naechster Plan/Phase}
2. {Danach}
3. {Danach}

### Offene Entscheidungen
- {Falls vorhanden}

### Blocker
- {Falls vorhanden, sonst "Keine"}
```

3. **Zeige den Report dem User** — kurz und praegnant

## Wichtig

- Keine Dateien aendern — nur lesen und berichten
- Velocity ehrlich berichten (keine Schoenrechnung)
- Offene Entscheidungen und Blocker hervorheben
