**errors.go:**

Also define a BookingConflictError struct that carries alternative suggestions:
```go
type BookingConflictError struct {
    ResourceName    string
    ConflictStart   time.Time
    ConflictEnd     time.Time
    Alternatives    []AlternativeResource
}

type AlternativeResource struct {
    ResourceID   uuid.UUID
    ResourceName string
    Capacity     *int
    Floor        *string
}

func (e *BookingConflictError) Error() string {
    return fmt.Sprintf("resource %s is booked from %s to %s", e.ResourceName, e.ConflictStart, e.ConflictEnd)
}
```

```go
type Repository interface {
    // Resources
    Create(ctx context.Context, resource *models.Resource) error
    GetByID(ctx context.Context, id uuid.UUID) (*models.Resource, error)
    List(ctx context.Context, filters ResourceFilters) ([]models.Resource, error)
    Update(ctx context.Context, resource *models.Resource) error
    Delete(ctx context.Context, id uuid.UUID) error

    // Bookings
    CreateBooking(ctx context.Context, booking *models.ResourceBooking) error
    CancelBooking(ctx context.Context, bookingID uuid.UUID) error
    ListBookings(ctx context.Context, resourceID uuid.UUID, start, end time.Time) ([]models.ResourceBooking, error)
    ListBookingsByEvent(ctx context.Context, eventID uuid.UUID) ([]models.ResourceBooking, error)
    GetBooking(ctx context.Context, bookingID uuid.UUID) (*models.ResourceBooking, error)

    // Availability
    FindAvailableResources(ctx context.Context, start, end time.Time, filters ResourceFilters) ([]models.Resource, error)
    FindAlternatives(ctx context.Context, excludeID uuid.UUID, start, end time.Time, resourceType string) ([]AlternativeResource, error)
}

type ResourceFilters struct {
    Type     *string
    MinCapacity *int
    Tags     []string
    Floor    *string
    IsActive *bool
}
```

**postgres_repository.go:**
Key implementation details:
- List: Build dynamic WHERE clause from ResourceFilters. For tags filter, use `resource_id IN (SELECT resource_id FROM resource_tags WHERE tag = ANY($N))`.
- CreateBooking: INSERT into resource_bookings. The EXCLUDE USING GIST constraint will reject double-bookings automatically. Catch the exclusion constraint violation error (pgx error code 23P01) and return ErrBookingConflict.
- FindAvailableResources: SELECT resources WHERE id NOT IN (SELECT resource_id FROM resource_bookings WHERE tstzrange(start_time, end_time) && tstzrange($start, $end) AND cancelled_at IS NULL). Apply filters.
- FindAlternatives: Similar to FindAvailableResources but excludes a specific resource and matches resource_type.
- SetTags: DELETE all existing tags + INSERT new ones (within transaction).

**service.go:**
Constructor takes Repository.

Key methods:
- `Create(ctx, actorID, req)` - validates input (name required, valid resource_type). Creates resource + sets tags if provided.
- `List(ctx, filters)` - pass through with active-only default.
- `Update(ctx, resourceID, actorID, changes)` - validates, updates. Only admin/managers can modify (check via role param).
- `Delete(ctx, resourceID, actorID)` - soft delete (set is_active = false) rather than hard delete. Existing bookings remain valid.
- `Book(ctx, actorID, resourceID, eventID, start, end)` - validates time range, checks resource is active. Attempts booking. If EXCLUDE constraint fires, catch error, fetch the conflicting booking details, find alternative resources matching same type, return BookingConflictError with alternatives.
- `CancelBooking(ctx, bookingID, actorID)` - verify actor is booking owner. Set cancelled_at.
- `ListAvailability(ctx, resourceID, date)` - list all bookings for a resource on a specific date (for timeline view).

**nager_client.go:**
HTTP client for the Nager.Date API (https://date.nager.at/api/v3/PublicHolidays/{year}/{countryCode}).

```go
type NagerClient struct {
    httpClient *http.Client
    baseURL    string
}

type NagerHoliday struct {
    Date         string   `json:"date"`
    LocalName    string   `json:"localName"`
    Name         string   `json:"name"`
    CountryCode  string   `json:"countryCode"`
    Fixed        bool     `json:"fixed"`
    Global       bool     `json:"global"`
    Counties     []string `json:"counties"` // ISO-3166-2 subdivision codes
    LaunchYear   *int     `json:"launchYear"`
    Types        []string `json:"types"` // "Public", "Bank", etc.
}

func NewNagerClient() *NagerClient // default baseURL: https://date.nager.at

func (c *NagerClient) FetchHolidays(ctx context.Context, year int, countryCode string) ([]NagerHoliday, error)
```

Fetch returns parsed JSON. Handle HTTP errors (non-200 status). Set timeout of 10 seconds. Set User-Agent header to "KMUHub/1.0".

Map NagerHoliday to models.PublicHoliday:
- Counties field maps to SubdivisionCodes (already ISO-3166-2 format)
- Types[0] maps to HolidayType (lowercase)
- Global field maps to IsGlobal
- Parse date string to time.Time

**repository.go (interface):**
```go
type Repository interface {
    BulkUpsert(ctx context.Context, holidays []models.PublicHoliday) error // INSERT ON CONFLICT UPDATE
    ListByDateRange(ctx context.Context, start, end time.Time, countryCode string, subdivisionCode *string) ([]models.PublicHoliday, error)
    HasDataForYear(ctx context.Context, year int, countryCode string) (bool, error)
    DeleteByYear(ctx context.Context, year int, countryCode string) error
}
```

**postgres_repository.go:**
- BulkUpsert: Use batch INSERT with ON CONFLICT (date, country_code, name) DO UPDATE for upsert.
- ListByDateRange: SELECT WHERE date BETWEEN start AND end AND country_code = $3. If subdivisionCode provided, also filter: AND (is_global = true OR $4 = ANY(subdivision_codes)).
- HasDataForYear: SELECT EXISTS (... WHERE year = $1 AND country_code = $2)

**service.go:**
Constructor takes Repository and NagerClient (NagerClient can be nil for environments without internet).

Key methods:
- `SeedHolidays(ctx, year, countryCode)` - fetches from Nager.Date API, maps to models, calls BulkUpsert. If NagerClient is nil, return ErrNagerAPIUnavailable. Supports countryCode: "DE", "AT", "CH".
- `SeedAllDACH(ctx, year)` - calls SeedHolidays for DE, AT, CH in sequence.
- `EnsureHolidaysLoaded(ctx, year, countryCode)` - checks HasDataForYear, if not, calls SeedHolidays. Lazy loading pattern.
- `ListHolidays(ctx, start, end, countryCode, subdivisionCode)` - calls EnsureHolidaysLoaded for the relevant year(s), then ListByDateRange. Handles year boundaries (e.g., Dec-Jan spans two years).

- Seed holidays (mock API response, verify bulk upsert called with correct data)
- Lazy loading (first call seeds, second call uses cache)
- List with subdivision filter (global holidays always included, subdivision-specific filtered)
- Year boundary handling (query spanning Dec-Jan loads both years)

```go
type Service struct {
    apiKey    string
    apiSecret string
    wsURL     string
    enabled   bool
}

func NewService(apiKey, apiSecret, wsURL string) *Service {
    return &Service{
        apiKey:    apiKey,
        apiSecret: apiSecret,
        wsURL:     wsURL,
        enabled:   apiKey != "" && apiSecret != "" && wsURL != "",
    }
}

func (s *Service) IsEnabled() bool
func (s *Service) GenerateRoomName(eventID uuid.UUID) string // "cal-{eventID[:8]}"
func (s *Service) GenerateMeetingLink(roomName string) string // "{wsURL}/room/{roomName}"
func (s *Service) GenerateJoinToken(roomName, userID, displayName string) (string, error)
```

Use `github.com/livekit/protocol/auth` for token generation. Set VideoGrant with RoomJoin=true, Room=roomName. SetIdentity to userID. SetName to displayName. SetValidFor to 24h.

If not enabled, GenerateJoinToken returns ErrLiveKitNotConfigured.
GenerateRoomName and GenerateMeetingLink work regardless of enabled state (they're just string formatting).
