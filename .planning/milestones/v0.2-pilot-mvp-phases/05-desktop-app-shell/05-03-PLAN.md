       - useContacts(params?: { page?, limit?, search? }): useQuery for GET /api/v1/contacts
       - useContact(id: string): useQuery for GET /api/v1/contacts/{id}
       - useCreateContact(): useMutation for POST /api/v1/contacts with query invalidation
       - useUpdateContact(): useMutation for PUT /api/v1/contacts/{id}
       - useDeleteContact(): useMutation for DELETE /api/v1/contacts/{id}
       - All hooks use apiClient from ../client.ts
       - All queries use proper queryKey arrays (e.g., ['contacts', params], ['contacts', id])
       - Mutations invalidate relevant query keys on success

    2. Create `api/hooks/useCompanies.ts`:
       - useCompanies(params?): GET /api/v1/companies
       - useCompany(id): GET /api/v1/companies/{id}
       - useCreateCompany, useUpdateCompany, useDeleteCompany mutations
       - useCompanyContacts(companyId): GET company contacts if endpoint exists

    3. Create `api/hooks/useDeals.ts`:
       - useDeals(params?): GET /api/v1/deals (with optional stage_id, search, sort params)
       - useDeal(id): GET /api/v1/deals/{id}
       - useCreateDeal, useUpdateDeal, useDeleteDeal mutations
       - useDealsByStage(stageId): useQuery filtered by stage (or use useDeals with stage_id param)

    4. Create `api/hooks/usePipelineStages.ts`:
       - usePipelineStages(): GET /api/v1/pipeline-stages
       - useCreateStage, useUpdateStage, useDeleteStage, useReorderStages mutations

    5. Create `api/hooks/useActivities.ts`:
       - useActivities(params?: { entity_type?, entity_id?, type?, page?, limit? }): GET /api/v1/activities
       - useActivity(id): GET /api/v1/activities/{id}
       - useCreateActivity, useUpdateActivity, useDeleteActivity, useCompleteActivity mutations

    6. Create `api/hooks/useSearch.ts`:
       - useCRMSearch(query: string, params?: { entity_type?, page?, limit? }): GET /api/v1/search
       - Enabled only when query.length >= 2 (avoid empty searches)

    Each hook file pattern:
    ```typescript
    import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
    import { apiClient } from '../client';

    export function useContacts(params?: { page?: number; limit?: number; search?: string }) {
      return useQuery({
        queryKey: ['contacts', params],
        queryFn: async () => {
          const { data, error } = await apiClient.GET('/api/v1/contacts', {
            params: { query: params },
          });
          if (error) throw error;
          return data;
        },
      });
    }
    ```

    IMPORTANT: Check the OpenAPI types.ts for exact path strings and parameter types. The paths must match exactly (e.g., '/api/v1/contacts' not '/contacts'). The generated types enforce this at compile time.

    - Query keys are properly structured arrays

  </verify>
