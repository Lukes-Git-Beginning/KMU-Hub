  <action>
    1. Create `stores/dashboard.ts` -- Zustand store with persist middleware:
       - State:
         - layouts: Record<string, Layout[]> -- keyed by role or 'personal' (react-grid-layout Layout type)
         - activeWidgets: string[] -- IDs of widgets currently on the dashboard
         - isEditing: boolean -- whether user is in edit mode (shows grid guides, add/remove controls)
       - Actions:
         - updateLayout(layout: Layout[]): save layout from react-grid-layout onLayoutChange
         - addWidget(widgetId: string, position?: {x, y}): add widget to activeWidgets and layouts
         - removeWidget(widgetId: string): remove from activeWidgets and layouts
         - toggleEditing(): toggle edit mode
         - resetToDefaults(): reset to role-based defaults
         - getDefaultLayout(role: string): return default widget set for a role
       - Persist to localStorage with key 'kmuhub-dashboard'
       - Default widgets for initial layout: recent-contacts, deal-pipeline, unread-messages, activity-feed, quick-actions, notification-summary
       - Default layout: 12-column grid, 2 rows of 3 widgets each (w:4, h:3 for most)

    2. Create `components/widgets/WidgetRegistry.tsx`:
       - Define WidgetDefinition interface:
         ```typescript
         interface WidgetDefinition {
           id: string;
           name: string;           // Display name (German)
           description: string;    // Short description
           icon: LucideIcon;       // Icon component
           defaultSize: { w: number; h: number };
           minSize: { w: number; h: number };
           maxSize?: { w: number; h: number };
           component: LazyExoticComponent<ComponentType<WidgetProps>>;
           roles: string[];        // Roles that see this by default
         }
         ```
       - Define WidgetProps interface: { widgetId: string; isEditing: boolean }
       - Register all 6 widgets:
         - recent-contacts: name "Letzte Kontakte", icon Users, default 4x3, min 2x2, roles: all
         - deal-pipeline: name "Deal Pipeline", icon TrendingUp, default 6x4, min 4x3, roles: admin, manager
         - unread-messages: name "Ungelesene Nachrichten", icon MessageSquare, default 4x3, min 2x2, roles: all
         - activity-feed: name "Aktivitaeten", icon Activity, default 4x4, min 3x3, roles: all
         - quick-actions: name "Schnellaktionen", icon Zap, default 4x2, min 2x2, roles: all
         - notification-summary: name "Benachrichtigungen", icon Bell, default 4x3, min 2x2, roles: all
       - Each component is lazy(() => import('../../modules/dashboard/widgets/...'))

    3. Create `components/widgets/WidgetWrapper.tsx`:
       - Wraps each widget component with:
         - Card container (rounded border, shadow, bg-white)
         - Header bar: widget name (from registry), remove button (X) visible in edit mode
         - Content area: Suspense with loading skeleton, ErrorBoundary for error isolation
         - Drag handle area at top (react-grid-layout uses className for drag handle)
       - React.memo the wrapper to prevent re-renders during drag

    4. Create `components/widgets/WidgetContainer.tsx`:
       - The main grid component using ReactGridLayout (from react-grid-layout)
       - Props: none (reads from dashboard store)
       - Configuration:
         - cols: 12
         - rowHeight: 80
         - width: computed from container ref (useRef + ResizeObserver)
         - isDraggable: isEditing (only allow drag in edit mode)
         - isResizable: isEditing
         - draggableHandle: '.widget-drag-handle'
         - compactType: 'vertical'
         - margin: [16, 16]
       - onLayoutChange: debounced (500ms) call to dashboard store updateLayout
       - Renders WidgetWrapper for each widget in activeWidgets
       - "Add Widget" floating button (visible in edit mode) -> opens widget picker dialog
       - Widget picker dialog: grid of available widgets (from registry) with name, description, icon. Click to add. Disable already-active widgets.
  </action>
  <verify>
    - `npx tsc --noEmit -p tsconfig.web.json` passes
    - WidgetRegistry exports definitions for 6 widgets
    - Dashboard store persists to localStorage
    - WidgetContainer uses react-grid-layout with 12-column grid
  </verify>
  <done>Widget infrastructure with registry of 6 widgets, grid container using react-grid-layout, wrapper with error isolation, dashboard store with layout persistence, and widget picker dialog for add/remove.</done>
