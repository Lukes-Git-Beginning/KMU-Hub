    FIRST: Read the OpenAPI spec and generated types.ts to understand exact chat endpoint paths, WebSocket message types, and response shapes. The backend WebSocket supports message types: message.new, message.updated, message.deleted, typing.start, typing.stop, channel.subscribe, channel.unsubscribe, read.receipt, thread.reply.new, file.uploaded.

    1. Create `api/hooks/useChannels.ts`:
       - useChannels(): GET /api/v1/channels (list all channels user is member of)
       - useChannel(id): GET /api/v1/channels/{id}
       - useCreateChannel(): POST /api/v1/channels
       - useJoinChannel(): POST /api/v1/channels/{id}/join
       - useLeaveChannel(): POST /api/v1/channels/{id}/leave
       - useChannelMembers(channelId): GET /api/v1/channels/{id}/members
       - useDMs(): GET /api/v1/channels/dm (list DM conversations)
       - useGetOrCreateDM(): POST /api/v1/channels/dm (create/get DM with specific user)

    2. Create `api/hooks/useMessages.ts`:
       - useMessages(channelId, params?): GET /api/v1/channels/{id}/messages (paginated, newest first)
       - useSendMessage(): POST /api/v1/channels/{id}/messages -- but ALSO send via WebSocket for real-time
       - useEditMessage(): PUT /api/v1/messages/{id}
       - useDeleteMessage(): DELETE /api/v1/messages/{id}
       - useMessageWebSocket(channelId): custom hook that:
         a) Subscribes to 'message.new' via wsManager.on
         b) On new message for current channel: append to query cache via queryClient.setQueryData
         c) Subscribes to 'message.updated', 'message.deleted' for cache updates
         d) Sends 'channel.subscribe' on mount, 'channel.unsubscribe' on unmount
         e) Returns { } (real-time cache updates are side effects)
       - NOTE: Typing indicators and thread replies are handled in Task 2

    3. Create `modules/chat/ChatLayout.tsx`:
       - Three-panel layout: channel list (left, 280px), message area (center, flex-1), thread panel (right, conditional 350px)
       - State: selectedChannelId, selectedThreadMessageId (for thread panel)
       - If no channel selected, show "Select a channel to start chatting"
       - Use flex layout with resizable-like borders

    4. Create `modules/chat/channels/ChannelList.tsx`:
       - Sections: "Channels" header with + button, "Direct Messages" header with + button
       - Channel items: # icon + channel name + unread badge
       - DM items: avatar + user name + unread badge + online dot (if available)
       - Active channel highlighted with bg-slate-100
       - Search/filter input at top
       - "Create Channel" button opens CreateChannelDialog
       - Click channel -> setSelectedChannelId
       - Use useChannels() and useDMs() hooks

    5. Create `modules/chat/channels/ChannelHeader.tsx`:
       - Channel name (# prefix for channels, no prefix for DMs)
       - Member count
       - Channel description (if exists)
       - Actions: members list button, search messages button

    6. Create `modules/chat/channels/CreateChannelDialog.tsx`:
       - Dialog with name input, description textarea, is_private toggle
       - Submit creates channel via useCreateChannel mutation
       - On success, close dialog and select new channel

    7. Create `modules/chat/messages/MessageList.tsx`:
       - Reverse-chronological message display (newest at bottom)
       - Infinite scroll: load older messages when scrolling to top (useMessages with cursor-based pagination if supported, else page-based)
       - Group messages by date with date separator
       - Use useMessages(selectedChannelId) hook
       - Use useMessageWebSocket(selectedChannelId) for real-time updates
       - Auto-scroll to bottom on new messages (only if user was already at bottom)
       - Loading skeleton during initial fetch
       - ScrollArea component from shadcn/ui

    8. Create `modules/chat/messages/MessageBubble.tsx`:
