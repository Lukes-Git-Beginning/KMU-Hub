       </body>
       </html>

    1. Create `src/preload/types.ts` defining the ElectronAPI interface:
       - Auth: getStoredTokens, storeTokens, clearTokens (all via safeStorage)
       - Notifications: showNativeNotification(title, body)
       - Window: minimize, maximize, close, isMaximized
       - App: getAppVersion, platform
       - Deep link: onDeepLink(callback) returning cleanup function

    2. Create `src/preload/index.ts`:
       - Import contextBridge and ipcRenderer from electron
       - Import ElectronAPI type from ./types
       - Implement each API method as specific ipcRenderer.invoke/send calls
       - Use channel naming convention: 'auth:get-tokens', 'auth:store-tokens', 'auth:clear-tokens', 'notification:show', 'window:minimize', 'window:maximize', 'window:close', 'window:is-maximized', 'app:version'
       - Expose via contextBridge.exposeInMainWorld('electronAPI', api)

    3. Create `src/main/ipc/auth.ts`:
       - Register 'auth:get-tokens' handler using Electron safeStorage API
       - Register 'auth:store-tokens' handler: encrypt with safeStorage, write to app.getPath('userData')/tokens.enc
       - Register 'auth:clear-tokens' handler: delete the encrypted file
       - If safeStorage.isEncryptionAvailable() is false, fall back to simple file storage with a logged warning (for Linux without keyring)

    4. Create `src/main/ipc/notifications.ts`:
       - Register 'notification:show' handler using Electron Notification API
       - On click, focus the main window
       - Check Notification.isSupported() before showing

    5. Create `src/main/ipc/window.ts`:
       - Register handlers for minimize, maximize (toggle), close, isMaximized
       - Get BrowserWindow from event.sender

    6. Create `src/main/ipc/index.ts`:
       - Export registerIPCHandlers() that calls all registration functions
       - Accept mainWindow parameter for window handlers

    7. Create `src/main/menu.ts`:
       - Create application menu using Menu.buildFromTemplate
       - Standard Edit menu (undo, redo, cut, copy, paste, select all)
       - View menu (reload, force reload, toggle dev tools, zoom in/out, reset zoom)
       - Window menu (minimize, close)
       - Help menu (about)

    8. Create `src/main/tray.ts`:
       - Export setupTray function that creates system tray icon
       - For now, use a placeholder (no icon file yet -- create tray without icon, or skip tray creation if icon missing)
       - Context menu: Show/Hide window, Quit
       - On tray click: toggle window visibility

    9. Create `src/main/index.ts` (main entry point):
       - Import app, BrowserWindow, shell from electron
       - Import path.join
       - Import registerIPCHandlers, setupTray, createMenu
       - Create BrowserWindow with secure webPreferences:
         - preload: join(__dirname, '../preload/index.js')
         - contextIsolation: true
         - nodeIntegration: false
         - sandbox: true
         - webSecurity: true
       - Window size: 1400x900, minWidth: 1024, minHeight: 700
       - show: false (wait for ready-to-show)
       - Native title bar (no frameless)
       - setWindowOpenHandler to deny and use shell.openExternal
       - ready-to-show: show window
       - Load URL: in dev -> process.env.ELECTRON_RENDERER_URL || 'http://localhost:5173', else -> file load from '../renderer/index.html'
       - app.whenReady: registerIPCHandlers, createWindow, createMenu, setupTray
       - app.on('window-all-closed'): quit on non-darwin
       - app.on('activate'): re-create window on macOS

    10. Create `src/renderer/src/global.d.ts`:
