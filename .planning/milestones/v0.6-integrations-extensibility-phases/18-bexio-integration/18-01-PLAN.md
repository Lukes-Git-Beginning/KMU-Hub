    **bexio_sync_configs** — per-tenant sync configuration:
    ```sql
    CREATE TABLE bexio_sync_configs (
        id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
        config_id UUID NOT NULL REFERENCES integration_configs(id) ON DELETE CASCADE,
        contact_sync_enabled BOOLEAN NOT NULL DEFAULT true,
        contact_sync_interval_minutes INTEGER NOT NULL DEFAULT 15,
        invoice_push_enabled BOOLEAN NOT NULL DEFAULT true,
        quote_push_enabled BOOLEAN NOT NULL DEFAULT true,
        payment_poll_enabled BOOLEAN NOT NULL DEFAULT true,
        payment_poll_interval_minutes INTEGER NOT NULL DEFAULT 5,
        last_contact_sync_at TIMESTAMPTZ,
        last_payment_poll_at TIMESTAMPTZ,
        created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
        updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
        UNIQUE(config_id)
    );
    ```

    **bexio_entity_mappings** — tracks KMU Hub ID <-> Bexio ID pairs:
    ```sql
    CREATE TABLE bexio_entity_mappings (
        id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
        config_id UUID NOT NULL REFERENCES integration_configs(id) ON DELETE CASCADE,
        entity_type VARCHAR(20) NOT NULL CHECK (entity_type IN ('contact', 'invoice', 'quote')),
        kmuhub_id UUID NOT NULL,
        bexio_id INTEGER NOT NULL,
        last_synced_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
        bexio_updated_at TIMESTAMPTZ,
        kmuhub_updated_at TIMESTAMPTZ,
        sync_direction VARCHAR(10) NOT NULL DEFAULT 'both' CHECK (sync_direction IN ('inbound', 'outbound', 'both')),
        created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
        updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
    );
    CREATE UNIQUE INDEX idx_bexio_entity_mappings_kmuhub ON bexio_entity_mappings(config_id, entity_type, kmuhub_id);
    CREATE UNIQUE INDEX idx_bexio_entity_mappings_bexio ON bexio_entity_mappings(config_id, entity_type, bexio_id);
    ```

    **bexio_field_mappings** — configurable field mapping per entity type:
    ```sql
    CREATE TABLE bexio_field_mappings (
        id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
        config_id UUID NOT NULL REFERENCES integration_configs(id) ON DELETE CASCADE,
        entity_type VARCHAR(20) NOT NULL CHECK (entity_type IN ('contact', 'invoice', 'quote')),
        mappings JSONB NOT NULL DEFAULT '[]',
        created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
        updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
        UNIQUE(config_id, entity_type)
    );
    ```

    The `mappings` JSONB structure: `[{"kmuhub_field": "email", "bexio_field": "mail", "direction": "both", "required": true}]`

    CREATE TABLE bexio_sync_log (
        id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
        config_id UUID NOT NULL REFERENCES integration_configs(id) ON DELETE CASCADE,
        sync_type VARCHAR(20) NOT NULL CHECK (sync_type IN ('contact_full', 'contact_delta', 'invoice_push', 'quote_push', 'payment_poll')),
        status VARCHAR(20) NOT NULL CHECK (status IN ('running', 'completed', 'failed', 'partial')),
        items_processed INTEGER NOT NULL DEFAULT 0,
        items_created INTEGER NOT NULL DEFAULT 0,
        items_updated INTEGER NOT NULL DEFAULT 0,
        items_failed INTEGER NOT NULL DEFAULT 0,
        error_message TEXT,
        started_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
        completed_at TIMESTAMPTZ,
        metadata JSONB NOT NULL DEFAULT '{}'
    );
    CREATE INDEX idx_bexio_sync_log_config ON bexio_sync_log(config_id, started_at DESC);

    ## Bexio Client Types

    Create `backend/internal/biz/bexio/types.go`:
    - `ClientConfig` struct: BaseURL, ClientID, ClientSecret, AuthURL, TokenURL, RedirectURL, Scopes
    - Default values for Bexio endpoints (base: `https://api.bexio.com/2.0/`, auth/token from CONTEXT)

    ## OAuth2 Token Manager

    Create `backend/internal/biz/bexio/auth.go`:
    - `TokenManager` struct holding vault service reference, in-memory access token cache with expiry
    - `NewTokenManager(vaultService, clientID, clientSecret, tokenURL)` constructor
    - `GetAccessToken(ctx, tenantID) (string, error)` — check cache, refresh if expired, return valid token
    - `RefreshAccessToken(ctx, tenantID) (string, error)` — load refresh token from vault (`bexio_oauth_refresh_{tenantID}`), call token endpoint, store new refresh token in vault, cache access token
    - `ExchangeCode(ctx, tenantID, code) error` — exchange authorization code for tokens, store in vault
    - `RevokeTokens(ctx, tenantID) error` — clear tokens from vault and cache
    - Use `sync.RWMutex` for thread-safe cache access
    - Log token refreshes via `slog.Info`

    ## Rate Limiter

    Create `backend/internal/biz/bexio/rate_limiter.go`:
    - `RateLimiter` struct with token bucket implementation
    - `Wait(ctx) error` — blocks until a request can be made
    - `UpdateFromHeaders(headers http.Header)` — reads `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` headers and adjusts internal state
    - Default: 50 requests per 10 seconds (adjusts based on response headers)

    ## Base HTTP Client

    Create `backend/internal/biz/bexio/client.go`:
    - `Client` struct with `http.Client`, `TokenManager`, `RateLimiter`, `baseURL`
    - `NewClient(config ClientConfig, vaultService) *Client`
    - `do(ctx, method, path, body, result) error` — core method that:
      1. Waits on rate limiter
      2. Gets access token from token manager
      3. Builds request with `Authorization: Bearer` header
      4. Sets `Content-Length: 0` for GET requests (Bexio quirk)
      5. Executes request
      6. Updates rate limiter from response headers
      7. On 429: exponential backoff (1s, 2s, 4s, max 3 retries)
      8. On 401: refresh token and retry once
      9. Decodes JSON response into result
    - `doList(ctx, path, params, result) error` — for paginated list endpoints with offset/limit
    - Structured logging for all API calls via `slog`
