    ## Setup Wizard

    Create `desktop/src/renderer/src/components/settings/BexioSetupWizard.tsx`:

    **4-Step Wizard (modal or full-page):**

    **Step 1: OAuth Verbindung**
    - Explanation text: "Verbinden Sie KMU Hub mit Ihrem Bexio-Konto"
    - "Mit Bexio verbinden" button → calls `getAuthorizationURL()`, opens URL in external browser (Electron `shell.openExternal`)
    - Waits for callback (polls connection status every 2s until connected)
    - On success: shows green checkmark, enables "Weiter" button

    **Step 2: Sync-Richtungen**
    - Toggles for each sync type:
      - Kontakte bidirektional synchronisieren (default: on)
      - Rechnungen an Bexio senden (default: on)
      - Offerten an Bexio senden (default: on)
      - Zahlungsstatus von Bexio abfragen (default: on)
    - Interval settings:
      - Kontakt-Sync Intervall: 15 min dropdown (5, 10, 15, 30, 60)
      - Zahlungs-Polling Intervall: 5 min dropdown (1, 5, 10, 15)

    **Step 3: Feld-Zuordnung**
    - Embedded `BexioFieldMappingEditor` for entity_type='contact'
    - Pre-populated with default mappings
    - Admin can add/remove/reorder mappings
    - "Standard wiederherstellen" button resets to defaults

    **Step 4: Erster Sync**
    - Summary of configuration
    - "Synchronisierung starten" button → calls `triggerSync()`
    - Progress indicator (polls sync status)
    - Shows result: X Kontakte synchronisiert, Y Fehler
    - "Fertig" button → closes wizard, returns to integrations page

    **Wizard Navigation:**
    - Stepper indicator at top (Step 1 of 4)
    - "Zurueck" / "Weiter" buttons
    - "Abbrechen" to exit (with confirmation if already connected)
