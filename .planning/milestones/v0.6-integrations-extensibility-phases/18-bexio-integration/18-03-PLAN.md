    ## Proto Definition

    Create `backend/proto/biz/v1/bexio.proto`:

    ```protobuf
    syntax = "proto3";
    package biz.v1;
    option go_package = "github.com/kmuhub/kmuhub/proto/biz/v1;bizv1";

    import "google/protobuf/timestamp.proto";

    service BexioIntegrationService {
        // OAuth
        rpc GetBexioAuthURL(GetBexioAuthURLRequest) returns (GetBexioAuthURLResponse);
        rpc HandleBexioOAuthCallback(HandleBexioOAuthCallbackRequest) returns (HandleBexioOAuthCallbackResponse);
        rpc DisconnectBexio(DisconnectBexioRequest) returns (DisconnectBexioResponse);
        rpc GetBexioConnectionStatus(GetBexioConnectionStatusRequest) returns (GetBexioConnectionStatusResponse);

        // Sync Operations
        rpc TriggerBexioSync(TriggerBexioSyncRequest) returns (TriggerBexioSyncResponse);
        rpc GetBexioSyncStatus(GetBexioSyncStatusRequest) returns (GetBexioSyncStatusResponse);
        rpc ListBexioSyncLogs(ListBexioSyncLogsRequest) returns (ListBexioSyncLogsResponse);

        // Field Mappings
        rpc GetBexioFieldMappings(GetBexioFieldMappingsRequest) returns (GetBexioFieldMappingsResponse);
        rpc UpdateBexioFieldMappings(UpdateBexioFieldMappingsRequest) returns (UpdateBexioFieldMappingsResponse);

        // Manual Push (for retries/manual triggers)
        rpc PushInvoiceToBexio(PushInvoiceToBexioRequest) returns (PushInvoiceToBexioResponse);
        rpc PushQuoteToBexio(PushQuoteToBexioRequest) returns (PushQuoteToBexioResponse);
    }
    ```

    - `HandleBexioOAuthCallbackResponse` — success, error_message
    - `DisconnectBexioRequest` — tenant_id
    - `DisconnectBexioResponse` — success
    - `GetBexioConnectionStatusRequest` — tenant_id
    - `GetBexioConnectionStatusResponse` — connected, org_name, connected_at

    - `ListBexioSyncLogsRequest` — tenant_id, limit
    - `ListBexioSyncLogsResponse` — repeated BexioSyncLogEntry
    - `BexioSyncLogEntry` — id, sync_type, status, items_processed, items_created, items_updated, items_failed, error_message, started_at, completed_at

    **Helper:** `getBexioClient() (bizv1.BexioIntegrationServiceClient, error)` — gets gRPC connection from registry ("biz" service) and creates client.

    **Route Registration** — called from `routes.go`:
    ```go
    func (br *BexioRoutes) Register(r chi.Router, authMiddleware, adminMiddleware func(http.Handler) http.Handler) {
        r.Route("/api/v1/integrations/bexio", func(r chi.Router) {
            // OAuth callback — NO auth (public, called by Bexio redirect)
            r.Get("/oauth/callback", br.HandleOAuthCallback)

            // Admin routes — require auth + admin role
            r.Group(func(r chi.Router) {
                r.Use(authMiddleware)
                r.Use(adminMiddleware)

                // OAuth management
                r.Get("/oauth/authorize", br.HandleGetAuthURL)
                r.Post("/disconnect", br.HandleDisconnect)
                r.Get("/status", br.HandleGetConnectionStatus)

                // Sync
                r.Post("/sync/trigger", br.HandleTriggerSync)
                r.Get("/sync/status", br.HandleGetSyncStatus)
                r.Get("/sync/logs", br.HandleListSyncLogs)

                // Field mappings
                r.Get("/mappings/{entity_type}", br.HandleGetFieldMappings)
                r.Put("/mappings/{entity_type}", br.HandleUpdateFieldMappings)

                // Manual push
                r.Post("/push/invoice/{invoice_id}", br.HandlePushInvoice)
                r.Post("/push/quote/{quote_id}", br.HandlePushQuote)
            })
        })
    }
    ```

    **Handler implementations** — all follow thin handler pattern:

    `HandleOAuthCallback`:
    - Extract `code` and `state` from query params
    - State contains encrypted tenant_id
    - Call gRPC `HandleBexioOAuthCallback`
    - Redirect to frontend settings page with success/error query param

    `HandleGetAuthURL`:
    - Extract tenant_id from auth context
    - Call gRPC `GetBexioAuthURL`
    - Return `{"authorization_url": "..."}`

    `HandleDisconnect`:
    - Call gRPC `DisconnectBexio`
    - Return 200 OK

    `HandleGetConnectionStatus`:
    - Call gRPC `GetBexioConnectionStatus`
    - Return `{"connected": true, "org_name": "...", "connected_at": "..."}`

    `HandleTriggerSync`:
    - Optional body: `{"sync_type": "contacts"}` — empty = all
    - Call gRPC `TriggerBexioSync`
    - Return 202 Accepted with sync_id

    `HandleGetSyncStatus`:
    - Call gRPC `GetBexioSyncStatus`
    - Return sync status per entity type

    `HandleListSyncLogs`:
    - Query param `limit` (default 20)
    - Call gRPC `ListBexioSyncLogs`
    - Return array of sync log entries

    `HandleGetFieldMappings` / `HandleUpdateFieldMappings`:
    - Entity type from URL param
    - Call gRPC methods
    - Return/accept field mapping arrays

    `HandlePushInvoice` / `HandlePushQuote`:
    - ID from URL param
    - Call gRPC push methods
    - Return success with Bexio ID
