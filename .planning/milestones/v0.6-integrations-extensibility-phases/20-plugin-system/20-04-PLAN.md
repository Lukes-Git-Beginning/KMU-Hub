# Plan 20-04: Industry Templates + Fuhrpark Reference Plugin

## Objective

Seed industry templates (Handwerk, Beratung, Handel), build the Fuhrpark WASM reference plugin with SDK, create the plugin service binary, and add Docker integration.

## Deliverables

1. **Migration 000058** -- Seed 3 industry templates (Handwerk, Beratung, Handel) with custom fields, validation rules, workflow rules
2. **Fuhrpark manifest** (plugins/fuhrpark/manifest.json) -- WASM plugin with German license plate validation, mileage tracking, maintenance workflows
3. **Fuhrpark WASM code** (plugins/fuhrpark/main.go + calculations.go) -- Hook handlers for contact create/update, maintenance checks, fuel cost tracking
4. **Plugin SDK** (plugin/sdk/) -- Host function imports (KV, logging, config), types, entry point marshalling
5. **Plugin service binary** (cmd/plugin/main.go) -- Standalone microservice
6. **Docker integration** (Dockerfile.plugin + docker-compose additions)
7. **Frontend: Template gallery + Fuhrpark page** -- IndustryTemplateGallery, ExecutionLogViewer, FuhrparkPage
8. **Documentation** (docs/PLUGIN_DEVELOPMENT.md) -- Complete plugin development guide

## Key Design Decisions

- 3 config-only templates (no WASM) for quick industry onboarding
- Fuhrpark as full WASM reference implementation demonstrating all SDK capabilities
- German license plate regex: ^[A-ZÄÖÜ]{1,3}-[A-Z]{1,2}\s?\d{1,4}[EH]?$
- Maintenance trigger at 15000 km interval (configurable via settings)
- Plugin binary: GOOS=wasip1 GOARCH=wasm go build
