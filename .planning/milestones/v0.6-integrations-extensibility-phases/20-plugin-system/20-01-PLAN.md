# Plan 20-01: Data Foundation + Config Validation Engine

## Objective

Create the database schema and config-based validation engine for the plugin system.

## Deliverables

1. **Migration 000057** -- 7 tables: plugin_manifests, plugin_installations, plugin_permissions, plugin_kv_store, validation_rules, workflow_rules, industry_templates
2. **Plugin models** (backend/internal/models/plugin.go) -- PluginType, InstallationStatus, ExecutionStatus, ValidationRuleType enums + all struct definitions
3. **Schema validator** (backend/internal/plugin/config/schema_validator.go) -- JSON Schema validation for plugin settings
4. **Validation engine** (backend/internal/plugin/config/validation_engine.go) -- 5 rule types: regex, range, required_if, format, enum
5. **Error definitions** (backend/internal/plugin/errors.go)

## Key Design Decisions

- plugin_type CHECK constraint (config | wasm) at DB level
- JSONB for settings_schema, hook_registrations, custom_fields, rule_config
- BYTEA for wasm_binary storage with SHA-256 hash
- Unique constraint on (tenant_id, manifest_id) for installations
- Partial indices on tenant_id + entity_type for validation rules
