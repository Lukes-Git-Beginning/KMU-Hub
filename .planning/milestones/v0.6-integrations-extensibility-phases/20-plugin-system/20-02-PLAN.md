# Plan 20-02: WASM Runtime + Sandbox

## Objective

Build the WASM execution environment with resource limits, rate limiting, and host API bridge.

## Deliverables

1. **Runtime** (wasm/runtime.go) -- wazero runtime with 64MB memory limit, module compilation + caching
2. **Sandbox** (wasm/sandbox.go) -- Execution isolation with 5s timeout, fresh instance per invocation
3. **Rate limiter** (wasm/ratelimiter.go) -- Token bucket (100 calls/min per plugin)
4. **Lifecycle manager** (wasm/lifecycle.go) -- Load, execute, unload plugins with execution logging
5. **Host API** (wasm/hostapi.go) -- KV store (get/set/delete), logging (info/warn/error), config access
6. **Memory helpers** (wasm/memory.go) -- Pointer-based data transfer between host and WASM

## Key Design Decisions

- wazero pure Go runtime (no CGO required)
- 64MB = 1024 pages x 64KB hard memory limit
- context.WithTimeout for execution deadline enforcement
- Rate limiting on all host API calls (not just WASM execution)
- Fresh module instance per execution for isolation
