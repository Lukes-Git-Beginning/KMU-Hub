  <action>
    Extend the WebSocketHub to support guest connections alongside user connections.

    **Struct changes:**
    Add to WebSocketHub struct:
    ```go
    // Guest connections: maps guest session ID to their connections
    guestConnections map[string]map[*websocket.Conn]struct{}
    // Guest session channel mapping: guest session ID -> channel ID (for isolation)
    guestChannels map[string]string
    // Guest service for token validation
    guestService GuestSessionValidator
    ```

    Define interface for dependency injection (avoids circular imports):
    ```go
    type GuestSessionValidator interface {
        ValidateToken(ctx context.Context, token string) (*GuestSessionInfo, error)
        CheckRateLimit(sessionID string) error
        UpdateLastActivity(ctx context.Context, sessionID uuid.UUID) error
    }

    type GuestSessionInfo struct {
        ID          uuid.UUID
        ChannelID   uuid.UUID
        DisplayName string
        IsActive    bool
    }
    ```

    Add `SetGuestService(svc GuestSessionValidator)` setter method (same pattern as SetPresenceService/SetVideoService).

    **HandleWebSocket changes:**
    Modify the auth flow at the beginning of HandleWebSocket:
    1. First check for `guest_token` query param
    2. If present: validate via guestService.ValidateToken, get GuestSessionInfo
    3. If valid: upgrade to WebSocket, register in guestConnections map, auto-subscribe to session's channel
    4. If not present: fall through to existing JWT token validation (existing flow unchanged)

    Guest connection lifecycle:
    - On connect: add to guestConnections[sessionID], auto-subscribe to guestChannels[sessionID]
    - On disconnect: remove from guestConnections, unsubscribe from channel
    - On message: only handle `message.send` and `typing.start`/`typing.stop` -- reject all other types with error

    **handleMessage changes for guests:**
    Add a `handleGuestMessage` method that:
    1. Only accepts message types: `message.send`, `typing.start`, `typing.stop`
    2. For `message.send`: verify channel matches session's channel (isolation), call guestService.CheckRateLimit, then delegate to sendMessage via gRPC
    3. For typing: broadcast typing indicator to channel (existing mechanism works, just use guest display name)
    4. All other message types: send error response `{"type":"error","payload":{"message":"not allowed for guests"}}`

    **broadcastToChannel changes:**
    The existing broadcastToChannel already sends to all users subscribed to a channel.
    Add guest broadcasting: after iterating userConnections, also iterate guestConnections for the channel:
    ```go
    // Also send to guest connections for this channel
    for sessionID, channelID := range h.guestChannels {
        if channelID == chID {
            if conns, ok := h.guestConnections[sessionID]; ok {
                for conn := range conns {
                    // send message
                }
            }
        }
    }
    ```

    **sendToGuest helper:**
    New method `sendToGuest(sessionID string, msg *WSMessage)` for sending messages to a specific guest.

    Initialize new maps in NewWebSocketHub constructor. Keep guestService nil-safe (check for nil before use).

    **route_guest.go** -- New gateway route handler for guest operations:

    ```go
    type GuestRoutes struct {
        guestService *guest.Service
        chatClient   chatv1.ChatServiceClient
        registry     *ServiceRegistry
    }

    func NewGuestRoutes(guestService *guest.Service, chatClient chatv1.ChatServiceClient, registry *ServiceRegistry) *GuestRoutes

    func (g *GuestRoutes) RegisterRoutes(r chi.Router) {
        // Public routes -- NO authMiddleware
        r.Route("/api/v1/guest", func(r chi.Router) {
            // Session management
            r.Post("/sessions", g.HandleCreateSession)        // create guest session (returns token)
            r.Post("/sessions/validate", g.HandleValidateToken) // validate token, get session info + config

            // Guest-authenticated routes (X-Guest-Token header)
            r.Group(func(r chi.Router) {
                r.Use(g.guestAuthMiddleware)
                r.Get("/channels/{channelID}/messages", g.HandleGetMessages)   // get messages in channel
                r.Post("/channels/{channelID}/messages", g.HandleSendMessage)  // send message
                r.Post("/channels/{channelID}/files", g.HandleUploadFile)      // upload file (10MB, images+PDF)
                r.Get("/config", g.HandleGetConfig)                             // get channel branding config
            })
        })
    }
    ```

    **guestAuthMiddleware:**
    - Extract token from `X-Guest-Token` header
    - Validate via guestService.ValidateToken
    - Store GuestSession in request context for downstream handlers
    - Return 401 if invalid/expired

    **HandleCreateSession:**
    - POST body: `{"channel_id": "...", "display_name": "...", "email": "..."}`
    - Validate channel_id exists and has is_guest_enabled=true

    **HandleGetMessages:**
