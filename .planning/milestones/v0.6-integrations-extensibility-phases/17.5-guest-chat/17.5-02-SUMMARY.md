## Accomplishments
- Extended WebSocket hub with dual-auth (JWT + guest token), guest connection maps, guest message handling, and channel-scoped broadcasting to guests
- Added GuestSessionID to message service CreateInput with membership check bypass for guest senders
- Added EnableGuest/DisableGuest/IsGuestEnabled to channel service

- Built GuestAdapter implementing ChannelAdapter for Unified Inbox normalization of guest messages
- Extended inbox proto Channel enum with CHANNEL_GUEST = 4
- Fixed all SQL queries (Create, GetByID, CreateWithReplyCount, List, ListReplies) to include guest_session_id
- Changed JOIN users to LEFT JOIN users + LEFT JOIN guest_sessions for mixed message listing
- Wired everything in gateway main.go: guest service, routes, adapter, WebSocket hub integration

## Decisions Made

- Guest GetMessages uses uuid.Nil as sentinel for guest access, gRPC server checks is_guest_enabled
- LEFT JOIN for both users and guest_sessions tables in message listing queries
- COALESCE for nullable first_name/last_name/display_name fields in SQL
