**Import Service (`email/contact/import_service.go`):**

```go
type ImportService struct {
    contactService ContactProvider // interface wrapping CRM contact service
    logger         *slog.Logger
}
```

Methods:
- `ImportCSV(ctx, reader io.Reader, fieldMapping map[string]string, visibility string, ownerID uuid.UUID, mergeByEmail bool) (*ImportResult, error)`
- `ImportVCard(ctx, reader io.Reader, visibility string, ownerID uuid.UUID, mergeByEmail bool) (*ImportResult, error)`
- `PreviewCSV(ctx, reader io.Reader) (*ImportPreview, error)` -- returns first 5 rows + detected columns for field mapping UI

ImportResult: `ImportedCount, MergedCount, SkippedCount int; Errors []ImportError`
ImportPreview: `Columns []string; SampleRows [][]string; DetectedMapping map[string]string` (auto-detect common column names: "Email", "E-Mail", "Vorname", "Nachname", "Firma", "Telefon", "Position")

CSV import flow (per user decision: step-by-step):
1. Parse CSV using `gocsv` or `encoding/csv` (detect delimiter: comma, semicolon, tab)
2. Apply field mapping: user-provided map of CSV column -> CRM field (first_name, last_name, email, phone, company, position, notes)
3. For each row:
   a. If `mergeByEmail=true` and email is not empty: look up existing contact by email
   b. If found: merge new non-empty fields into existing contact (don't overwrite non-empty fields with empty). Increment MergedCount.
   c. If not found: create new contact with specified visibility and owner_id. Increment ImportedCount.
   d. If row has errors (e.g., invalid email format): skip, add to Errors. Increment SkippedCount.
4. Return ImportResult

vCard import flow:
1. Parse vCard file using `go-vcard` Decoder
2. For each vCard entry: extract FN (full name, split into first/last), EMAIL, TEL, ORG, TITLE, NOTE
3. Same merge/create logic as CSV
4. Return ImportResult

Auto-detection for CSV field mapping:
```go
var knownMappings = map[string]string{
    "email": "email", "e-mail": "email", "mail": "email",
    "vorname": "first_name", "first name": "first_name", "firstname": "first_name",

    "firma": "company", "company": "company", "unternehmen": "company", "organisation": "company",

    "position": "position", "titel": "position", "title": "position", "job title": "position",
    "notizen": "notes", "notes": "notes", "bemerkung": "notes",
}
```

```go

}
```

Methods:
- `SetVisibility(ctx, contactID uuid.UUID, visibility string, userID uuid.UUID) error` -- set shared/personal
- `SetOwner(ctx, contactID uuid.UUID, ownerID uuid.UUID) error` -- set owner for personal contacts
- `AdminOverride(ctx, contactID uuid.UUID, visibility string) error` -- admin can force visibility change

Visibility rules (per user decision):
- `shared`: visible to all users in the organization. Default for manually created contacts.
- `personal`: visible only to owner_id. Other users cannot see it in list views or search.
- Admin override: admin role can view and edit any contact regardless of visibility.
