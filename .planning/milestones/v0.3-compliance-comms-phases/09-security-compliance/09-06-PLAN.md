       - gdpr.Service

  <name>Task 2: Gateway HTTP routes + IP filter middleware</name>
  <files>

  <action>
    1. Create `backend/internal/gateway/ip_filter.go`:
       - `type IPFilterMiddleware struct` with list of allow/block rules loaded from database (cached, refresh every 60 seconds)
       - `func NewIPFilterMiddleware(securityClient securityv1.SecurityServiceClient) *IPFilterMiddleware`
       - `func (m *IPFilterMiddleware) Handler(next http.Handler) http.Handler` -- checks client IP against rules. If blocklist match: return 403. If allowlist exists and IP not in allowlist: return 403. If no rules: allow all. Use `net.ParseCIDR` for CIDR matching.
       - Extract client IP from X-Forwarded-For header (first IP) or r.RemoteAddr.
       - Cache rules in memory with sync.RWMutex, refresh via background goroutine every 60s.

    2. Extend `backend/internal/gateway/route_auth.go` with new endpoints in RegisterRoutes:
       Protected auth routes (require authMiddleware):
       - `POST /api/v1/auth/2fa/setup` -> HandleSetup2FA (calls Setup2FA gRPC)
       - `POST /api/v1/auth/2fa/verify` -> HandleVerify2FA (calls Verify2FA gRPC)
       - `POST /api/v1/auth/2fa/disable` -> HandleDisable2FA (calls Disable2FA gRPC)
       - `POST /api/v1/auth/2fa/regenerate-codes` -> HandleRegenerateRecoveryCodes
       - `GET /api/v1/auth/2fa/policy` -> HandleGetTwoFactorPolicies (admin)
       - `PUT /api/v1/auth/2fa/policy` -> HandleUpdateTwoFactorPolicy (admin)
       - `POST /api/v1/auth/2fa/admin-reset` -> HandleAdminReset2FA (admin, requires reason field)

       Public auth route (no authMiddleware):
       - `POST /api/v1/auth/2fa/validate` -> HandleValidate2FALogin (accepts pending_token + code)

       Modify existing HandleLogin to return the new fields (requires_two_factor, pending_token) from the updated LoginResponse proto.

       Session routes (protected):
       - `GET /api/v1/auth/sessions` -> HandleListSessions (user's own sessions)
       - `GET /api/v1/auth/sessions/all` -> HandleListAllSessions (admin only)
       - `DELETE /api/v1/auth/sessions/{id}` -> HandleTerminateSession
       - `DELETE /api/v1/auth/sessions` -> HandleTerminateAllSessions

    3. Create `backend/internal/gateway/route_security.go` following RouteRegistrar pattern:
       - `type SecurityRoutes struct { registry *ServiceRegistry }` + `NewSecurityRoutes(registry *ServiceRegistry) *SecurityRoutes`
       - ServiceName returns "auth" (security service runs on same gRPC port as auth)
       - `getSecurityClient()` returns securityv1.SecurityServiceClient

       All routes require authMiddleware + admin RBAC check (except user GDPR endpoints):

       Audit routes:
       - `GET /api/v1/security/audit` -> HandleListAuditEntries (query params: date_from, date_to, user_id, action, result, offset, limit)
       - `GET /api/v1/security/audit/export` -> HandleExportAuditLog (query params: format=csv|json, same filters)
       - `POST /api/v1/security/audit/verify` -> HandleVerifyAuditChain (body: from_sequence, to_sequence)

       Vault routes (admin only):
       - `GET /api/v1/security/vault` -> HandleListVaultSecrets
       - `GET /api/v1/security/vault/{keyName}` -> HandleGetVaultSecret
       - `PUT /api/v1/security/vault/{keyName}` -> HandleSetVaultSecret (body: value, description)
       - `DELETE /api/v1/security/vault/{keyName}` -> HandleDeleteVaultSecret

       GDPR routes:
       - `POST /api/v1/security/gdpr/export` -> HandleRequestExport (user's own, requires auth but not admin)
       - `GET /api/v1/security/gdpr/exports` -> HandleListExports (admin: all; user: own)
       - `POST /api/v1/security/gdpr/export/{id}/approve` -> HandleApproveExport (admin)
       - `POST /api/v1/security/gdpr/export/{id}/deny` -> HandleDenyExport (admin, body: note)
       - `GET /api/v1/security/gdpr/export/download/{token}` -> HandleDownloadExport (public with token)
       - `POST /api/v1/security/gdpr/erasure/preview` -> HandlePreviewErasure (admin, body: user_id)
       - `POST /api/v1/security/gdpr/erasure/execute` -> HandleExecuteErasure (admin, body: user_id, module_actions, password for confirmation)

       Password policy routes (admin only):
       - `GET /api/v1/security/password/policy` -> HandleGetPasswordPolicy
       - `PUT /api/v1/security/password/policy` -> HandleUpdatePasswordPolicy
       - `POST /api/v1/security/password/validate` -> HandleValidatePassword (body: password; returns validation result, no admin required)

       IP access rules (admin only):
       - `GET /api/v1/security/ip-rules` -> HandleListIPRules
       - `POST /api/v1/security/ip-rules` -> HandleCreateIPRule (body: ip_cidr, rule_type, description)
       - `DELETE /api/v1/security/ip-rules/{id}` -> HandleDeleteIPRule

    4. Update `backend/cmd/gateway/main.go`:
       - Register SecurityRoutes as a new RouteRegistrar
       - Apply IPFilterMiddleware to admin routes (or all routes, configurable)

    5. Update `deploy/docker/docker-compose.yml`:
       - Add VAULT_MASTER_SECRET env var to auth service (use a development default)
       - Ensure auth service env has all needed vars
