    **1. InboxService Proto** (`backend/proto/inbox/v1/inbox.proto`):

    Create inbox.proto with `package inbox.v1;` and `option go_package = "github.com/kmuhub/kmuhub/proto/inbox/v1;inboxv1";`.

    Define the InboxService with ~27 RPCs in three groups:

    **Messages (14 RPCs):**
    - ListMessages (filters: channel, is_read, is_starred, is_archived, team_inbox_id, search query; pagination: page_size + page_token; sort by received_at DESC)
    - GetMessage (by ID, returns full message with metadata)
    - MarkRead / MarkUnread (by message ID)
    - ToggleStar (by message ID)
    - ArchiveMessage / UnarchiveMessage (by message ID)
    - SnoozeMessage (message_id + snooze_until timestamp)
    - UnsnoozeMessage (by message ID)
    - ReplyToMessage (message_id + body string; backend routes reply through originating channel)
    - AssignMessage (message_id + assignee user_id)
    - GetUnreadCount (returns count per channel + total)
    - BulkMarkRead (list of message IDs)
    - BulkArchive (list of message IDs)

    **Team Inboxes (8 RPCs):**
    - CreateTeamInbox (name, description, assignment_mode: MANUAL/ROUND_ROBIN, visibility: OPEN/PRIVATE)
    - UpdateTeamInbox (same fields)
    - DeleteTeamInbox (by ID)
    - ListTeamInboxes (returns all team inboxes the user is a member of)
    - AddTeamMember (team_inbox_id, user_id, role: ADMIN/MEMBER)
    - RemoveTeamMember (team_inbox_id, user_id)
    - ListTeamMembers (team_inbox_id)
    - ClaimMessage (message_id; atomic claim with "already assigned" error)

    **Routing Rules (5 RPCs):**
    - CreateRoutingRule (name, channel filter, conditions JSON, actions JSON, priority)
    - UpdateRoutingRule (same fields)
    - DeleteRoutingRule (by ID)
    - ListRoutingRules (filter by channel, active only)
    - TestRoutingRule (conditions + test message; returns whether it would match)

    Message types for all requests/responses. Use `google.protobuf.Timestamp` for time fields, `google.protobuf.Struct` for conditions/actions JSONB fields. Channel as enum: CHANNEL_EMAIL, CHANNEL_CHAT, CHANNEL_NOTIFICATION.

    TeamInbox assignment_mode as enum: ASSIGNMENT_MODE_MANUAL, ASSIGNMENT_MODE_ROUND_ROBIN.
    TeamInbox visibility as enum: VISIBILITY_OPEN, VISIBILITY_PRIVATE.
    TeamMember role as enum: TEAM_ROLE_ADMIN, TEAM_ROLE_MEMBER.

    Run `make proto` from backend/ to generate Go code.

    2. Define an `EventEmitter` interface with a single method (e.g., `EmitEmailEvent(ctx, payload)`)
    3. Implement `PGEventEmitter` struct with pgxpool.Pool field
    4. Constructor `NewPGEventEmitter(pool) *PGEventEmitter`
