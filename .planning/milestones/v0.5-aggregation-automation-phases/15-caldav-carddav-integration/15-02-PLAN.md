    **ETag utility** in `backend/internal/caldav/etag.go`:
    - `GenerateETag(id uuid.UUID, updatedAt time.Time) string`: SHA-256 hash of UUID bytes + updatedAt.UnixNano(), return first 16 bytes hex-encoded wrapped in quotes. Deterministic -- same input always produces same ETag.
    - `GenerateCTag(syncVersion int64) string`: Return `"ctag-{syncVersion}"` string.

    **VTIMEZONE generator** in `backend/internal/caldav/vtimezone.go`:
    - `GenerateVTimezone(tzName string) (*ical.Component, error)`: Load timezone via `time.LoadLocation(tzName)`. Build VTIMEZONE component with STANDARD and DAYLIGHT subcomponents for Europe/Berlin (CET/CEST). For the Deutschland-first approach, hardcode Europe/Berlin VTIMEZONE definition (DTSTART, RRULE for CET->CEST and CEST->CET transitions, TZOFFSETFROM, TZOFFSETTO). For other timezone names, generate a minimal VTIMEZONE with just the name and current offset. Cache generated components in a sync.Map for performance.
    - Note: All events in KMU Hub store a timezone string. The converter calls this for each unique timezone referenced.

    **iCalendar converter** in `backend/internal/caldav/ical_converter.go`:

    `EventToICal(event *models.CalendarEvent, exceptions []models.EventException, attendees []models.EventAttendee) (*ical.Calendar, error)`:
    - Create ical.Calendar with VERSION:2.0, PRODID:-//KMU Hub//CalDAV//DE
    - Add VTIMEZONE component(s) for referenced timezone(s) via GenerateVTimezone
    - Create master VEVENT: UID = event.ID.String(), DTSTAMP = event.UpdatedAt, SUMMARY = event.Title
    - Set DTSTART/DTEND: If IsAllDay, use DATE value type (no time); otherwise DATETIME with TZID parameter
    - Set DESCRIPTION, LOCATION if non-nil
    - Set RRULE if non-nil
    - Add EXDATE for each cancelled exception (exc.IsCancelled = true)
    - Add ATTENDEE properties: `urn:uuid:{att.UserID}` with CN and PARTSTAT params. Map RSVP status: pending->NEEDS-ACTION, accepted->ACCEPTED, declined->DECLINED, tentative->TENTATIVE
    - For non-cancelled exceptions with overrides: create additional VEVENT with same UID, RECURRENCE-ID = exc.OriginalDate, overridden fields from exception

    `ICalToEventInput(cal *ical.Calendar) (*CalEventInput, []*CalExceptionInput, error)`:
    - Parse the first VEVENT without RECURRENCE-ID as the master event
    - Extract Title from SUMMARY, Description from DESCRIPTION, Location from LOCATION
    - Parse DTSTART/DTEND (detect VALUE=DATE for all-day), RRULE, TZID for timezone
    - Parse VEVENTs WITH RECURRENCE-ID as exceptions (modified occurrences)
    - Parse EXDATE properties as cancelled exceptions
    - Return structured input types (not models directly -- let the caller map to create/update requests)

    Define intermediate types:
    ```go
    type CalEventInput struct {
        Title       string
        Description *string
        Location    *string
        StartTime   time.Time
        EndTime     time.Time
        IsAllDay    bool
        Timezone    string
        RRule       *string
    }

    type CalExceptionInput struct {
        OriginalDate time.Time
        IsCancelled  bool
        Title        *string
        StartTime    *time.Time
        EndTime      *time.Time
    }
    ```

    **vCard converter** in `backend/internal/caldav/vcard_converter.go`:

    `ContactToVCard(contact *models.Contact) vcard.Card`:
    - Set VERSION:4.0
    - Set FN (Formatted Name): "{FirstName} {LastName}"
    - Set N (Name): LastName;FirstName;;;
    - Set EMAIL if non-nil
    - Set TEL if non-nil
    - Set ORG from CompanyName (if ContactWithRelations available, otherwise skip)
    - Set TITLE from Position if non-nil
    - Set NOTE from Notes if non-nil
    - Set UID: contact.ID.String()
    - Set REV: contact.UpdatedAt in ISO 8601 format

    `VCardToContactInput(card vcard.Card) *ContactInput`:
    - Parse FN or N for FirstName/LastName
    - Parse EMAIL (first value)
    - Parse TEL (first value)
    - Parse TITLE for Position
    - Parse NOTE for Notes
    - Return structured input (caller handles visibility based on address book)

    Define intermediate type:
    ```go
    type ContactInput struct {
        FirstName string
        LastName  string
        Email     *string
        Phone     *string
        Position  *string
        Notes     *string
    }
    ```

    Use emersion/go-ical for iCalendar types and emersion/go-vcard (already in go.mod) for vCard types.

    **CalDAV Backend** in `backend/internal/caldav/caldav_backend.go`:

    Implement `caldav.Backend` interface from go-webdav. The Backend needs access to the calendar gRPC service via ServiceRegistry and to SyncTokenService.

    ```go
    type CalDAVBackend struct {
        registry    *gateway.ServiceRegistry
        syncService *SyncTokenService
        pool        *pgxpool.Pool
    }

    func NewCalDAVBackend(registry *gateway.ServiceRegistry, syncService *SyncTokenService, pool *pgxpool.Pool) *CalDAVBackend
    ```

    Context key pattern for authenticated user (set by Basic Auth middleware):
    ```go
    type caldavUserKey struct{}

    func UserFromCtx(ctx context.Context) uuid.UUID {
        return ctx.Value(caldavUserKey{}).(uuid.UUID)
    }

    func CtxWithUser(ctx context.Context, userID uuid.UUID) context.Context {
        return context.WithValue(ctx, caldavUserKey{}, userID)
    }
    ```

    Implement caldav.Backend methods:

    - `CurrentUserPrincipal(ctx) (string, error)`: Return `/caldav/principals/{userID}/`
    - `CalendarHomeSetPath(ctx) (string, error)`: Return `/caldav/principals/{userID}/calendars/`
    - `ListCalendars(ctx) ([]caldav.Calendar, error)`: Call calendar gRPC ListCalendars for user. Map each to caldav.Calendar with Path, Name, Description, SupportedComponentSet:["VEVENT"]. Include CTag from SyncTokenService.
    - `GetCalendar(ctx, path) (*caldav.Calendar, error)`: Parse calendar_id from path, call gRPC GetCalendar, map to caldav.Calendar.
    - `GetCalendarObject(ctx, path, req) (*caldav.CalendarObject, error)`: Parse event_id from path (strip .ics). Call gRPC GetEvent + ListEventAttendees + get exceptions. Convert via EventToICal. Return caldav.CalendarObject with Path, ModTime, ETag, Data (ical.Calendar).
    - `ListCalendarObjects(ctx, path, req) ([]caldav.CalendarObject, error)`: Parse calendar_id from path. Call gRPC ListEventsInRange (use wide range: 2 years back, 2 years forward if no filter). For each event, build CalendarObject with EventToICal.
    - `QueryCalendarObjects(ctx, path, query) ([]caldav.CalendarObject, error)`: Similar to List but with time-range filter from query.CompFilter.
    - `PutCalendarObject(ctx, path, cal, opts) (*caldav.CalendarObject, error)`: Parse calendar_id and event_uid from path. Convert incoming iCal via ICalToEventInput. If event exists (GetEvent succeeds), call UpdateEvent/UpdateRecurringEvent. If not, call CreateEvent. Handle exceptions: for each CalExceptionInput, update/create exception via UpdateRecurringEvent with scope="this". Increment sync token. Return new CalendarObject with updated ETag.
    - `DeleteCalendarObject(ctx, path) error`: Parse event_id from path, call gRPC DeleteEvent. Increment sync token with changeType "deleted".

    Path parsing helpers:
    - `calendarIDFromPath(path string) (uuid.UUID, error)`: Extract calendar UUID from path like `/caldav/principals/{uid}/calendars/{calID}/`
    - `eventUIDFromPath(path string) (string, error)`: Extract event UID from path like `.../calendars/{calID}/{eventUID}.ics`

    For write operations, check calendar permissions: personal calendar = full write; team calendar = check user role via auth gRPC (admin/manager = write, member = read-only). Return `webdav.NewHTTPError(http.StatusForbidden, ...)` for unauthorized writes.

    **CardDAV Backend** in `backend/internal/caldav/carddav_backend.go`:

    Implement `carddav.Backend` interface from go-webdav.

    ```go
    type CardDAVBackend struct {
        registry    *gateway.ServiceRegistry
        syncService *SyncTokenService
        pool        *pgxpool.Pool
    }

    func NewCardDAVBackend(registry *gateway.ServiceRegistry, syncService *SyncTokenService, pool *pgxpool.Pool) *CardDAVBackend
    ```

    Implement carddav.Backend methods:

    - `CurrentUserPrincipal(ctx) (string, error)`: Return `/carddav/principals/{userID}/`
    - `AddressBookHomeSetPath(ctx) (string, error)`: Return `/carddav/principals/{userID}/addressbooks/`
    - `ListAddressBooks(ctx) ([]carddav.AddressBook, error)`: Return 2 address books per user:
      1. "personal" with Path `.../addressbooks/personal/`, Name "Meine Kontakte"
      2. "company" with Path `.../addressbooks/company/`, Name "Firmenkontakte"
    - `GetAddressBook(ctx, path) (*carddav.AddressBook, error)`: Parse book type from path, return matching address book.
    - `GetAddressObject(ctx, path, req) (*carddav.AddressObject, error)`: Parse contact_id from path (strip .vcf). Call CRM gRPC GetContact. Convert via ContactToVCard. Return carddav.AddressObject with Path, ModTime, ETag, Card.
    - `ListAddressObjects(ctx, path, req) ([]carddav.AddressObject, error)`: Parse book type. For "personal": ListContacts with visibility=personal, owner_id=userID. For "company": ListContacts with visibility=shared. Map each contact via ContactToVCard.
    - `QueryAddressObjects(ctx, path, query) ([]carddav.AddressObject, error)`: Similar to List.
    - `PutAddressObject(ctx, path, card, opts) (*carddav.AddressObject, error)`: Parse book type and contact_id from path. ACL check: if "company" book, user must have admin/manager role -- return 403 Forbidden otherwise. Convert vCard via VCardToContactInput. If contact exists, UpdateContact. If not, CreateContact with visibility matching book type (personal/shared). Set owner_id for personal contacts. Increment sync token.
    - `DeleteAddressObject(ctx, path) error`: Parse contact_id. Check permissions (personal = owner only; company = admin/manager). Call CRM gRPC DeleteContact. Increment sync token.

    Both backends get gRPC clients via `registry.GetConnection("work")` for calendar and `registry.GetConnection("crm")` for contacts. Handle gRPC errors gracefully: NotFound -> return appropriate webdav HTTP error, Unavailable -> return 503.

    The user_id for gRPC calls comes from UserFromCtx(ctx) -- injected by the Basic Auth middleware (registered in Plan 15-03).
