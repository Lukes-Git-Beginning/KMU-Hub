    **Time Tracking Service Package (`backend/internal/biz/hr/timetracking/`)**

    This is HR work time tracking (ArbZG compliance), completely SEPARATE from Phase 6 task timer (`internal/work/timeentry/`). Different table, different service, different rules.

    Create `errors.go` with domain errors:
    - ErrAlreadyClockedIn, ErrNotClockedIn, ErrAlreadyOnBreak, ErrNotOnBreak, ErrShiftAlreadyCompleted, ErrCorrectionNotFound, ErrNotAuthorizedToApproveCorrection, ErrMaxDailyHoursExceeded (ArbZG block at 10h)

    Create `repository.go` with interfaces:

    ```go
    type WorkTimeRepository interface {
        Create(ctx context.Context, entry *models.WorkTimeEntry) error
        GetByID(ctx context.Context, id uuid.UUID) (*models.WorkTimeEntry, error)
        GetActiveShift(ctx context.Context, employeeID uuid.UUID) (*models.WorkTimeEntry, error)
        Update(ctx context.Context, entry *models.WorkTimeEntry) error
        List(ctx context.Context, filter WorkTimeFilter) ([]*models.WorkTimeEntry, int, error)
        GetPreviousShiftEnd(ctx context.Context, employeeID uuid.UUID, before time.Time) (*time.Time, error)
        GetDailySummary(ctx context.Context, employeeID uuid.UUID, date time.Time) (*DailySummary, error)
        GetWeeklySummary(ctx context.Context, employeeID uuid.UUID, weekStart time.Time) (*WeeklySummary, error)
    }

    type BreakRepository interface {
        Create(ctx context.Context, entry *models.BreakEntry) error
        GetActiveBreak(ctx context.Context, workTimeEntryID uuid.UUID) (*models.BreakEntry, error)
        Update(ctx context.Context, entry *models.BreakEntry) error
        ListByWorkTimeEntry(ctx context.Context, workTimeEntryID uuid.UUID) ([]*models.BreakEntry, error)
    }
    ```

    `WorkTimeFilter`: TenantID, EmployeeID, DateFrom, DateTo, Status, Page, PerPage.
    `DailySummary`: Date, TotalWorkedMinutes, TotalBreakMinutes, NetWorkMinutes, OvertimeMinutes (net - contracted daily hours * 60), EntryCount.
    `WeeklySummary`: WeekStart, Days []DailySummary, TotalWorkedMinutes, TotalBreakMinutes, NetWorkMinutes, TotalOvertimeMinutes.

    Create `postgres_repository.go` implementing both interfaces:
    - GetActiveShift: SELECT WHERE employee_id = $1 AND status = 'active' LIMIT 1
    - GetPreviousShiftEnd: SELECT clock_out FROM hr_work_time_entries WHERE employee_id = $1 AND clock_out IS NOT NULL AND clock_in < $2 ORDER BY clock_in DESC LIMIT 1
    - GetDailySummary: Aggregate work time entries for a single date (using timezone-aware date extraction from clock_in)
    - GetWeeklySummary: Aggregate by day for the week (Monday-Sunday)
    - Break entries: standard CRUD linked to work_time_entry_id

    Create `service.go` with `Service` struct:
    ```go
    type Service struct {
        workTimeRepo   WorkTimeRepository
        breakRepo      BreakRepository
        employeeRepo   employee.EmployeeRepository
        settingsRepo   leave.HRSettingsRepository
        pool           *pgxpool.Pool  // For event emission
    }
    ```

    Service methods:

    - `ClockIn(ctx, tenantID, employeeID uuid.UUID) (*models.WorkTimeEntry, *compliance.WorkTimeCheckResult, error)`:
      - Check no active shift exists (ErrAlreadyClockedIn)
      - Check 11-hour rest period: get previous shift end, run compliance.CheckRestPeriod
      - If rest violation: return warning in result but still allow clock-in (informational, not blocking)
      - **ArbZG 10h block:** Get today's DailySummary. If net work minutes >= 600 (10h), return ErrMaxDailyHoursExceeded. This prevents starting additional shifts after 10h has been reached for the day (per locked decision: "block at 10h").
      - Create new WorkTimeEntry with status "active", clock_in = now
      - Return entry + rest period check result (for frontend toast)

    - `ClockOut(ctx, tenantID, employeeID uuid.UUID) (*models.WorkTimeEntry, *compliance.WorkTimeCheckResult, error)`:
      - Get active shift (ErrNotClockedIn if none)
      - Calculate total worked minutes from clock_in to now
      - Get manual breaks for this shift, sum break_minutes
      - Run compliance.CalculateRequiredBreak and compliance.CalculateAutoBreakDeduction
      - Set auto_break_deducted on the entry
      - Calculate net_work_minutes = total - manual_breaks - auto_deduction
      - Run compliance.CheckWorkTime on total worked minutes (for severity/toast)
      - If severity = Error (>10h): still allow clock-out but include the warning
      - Set clock_out = now, status = "completed"
      - Update entry
      - Return entry + compliance check result

    - `StartBreak(ctx, employeeID uuid.UUID) (*models.BreakEntry, error)`:
      - Get active shift (ErrNotClockedIn)
      - Check no active break (ErrAlreadyOnBreak)
      - Create BreakEntry with start_time = now, work_time_entry_id = shift.ID
      - Return break entry

    - `EndBreak(ctx, employeeID uuid.UUID) (*models.BreakEntry, error)`:
      - Get active shift
      - Get active break for this shift (ErrNotOnBreak)
      - Set end_time = now, calculate duration_minutes
      - Update shift's break_minutes (sum of all completed breaks)
      - Return updated break entry

    - `GetActiveShift(ctx, employeeID uuid.UUID) (*models.WorkTimeEntry, []*models.BreakEntry, error)`:
      - Return active shift + its break entries (for display)

    - `ListWorkTimeEntries(ctx, filter WorkTimeFilter) ([]*models.WorkTimeEntry, int, error)`: delegate to repo
    - `GetDailySummary(ctx, employeeID uuid.UUID, date time.Time) (*DailySummary, error)`: delegate to repo
    - `GetWeeklySummary(ctx, employeeID uuid.UUID, weekStart time.Time) (*WeeklySummary, error)`: delegate to repo

    - `SubmitTimeCorrection(ctx, tenantID, employeeID uuid.UUID, input CorrectionInput) (*models.WorkTimeEntry, error)`:
      - CorrectionInput: OriginalEntryID, CorrectedClockIn, CorrectedClockOut, CorrectedBreakMinutes, Reason
      - Create new WorkTimeEntry with is_correction=true, original_entry_id, status="correction_pending", correction_reason
      - Emit "hr.time.correction_requested" event to employee's manager

    - `ApproveTimeCorrection(ctx, correctionID, approverID uuid.UUID) (*models.WorkTimeEntry, error)`:
      - Validate correction status is "correction_pending"
      - Set correction_approved_by, correction_approved_at, status="correction_approved"
      - Mark original entry as superseded (or leave it -- corrections append, don't replace)
      - Emit "hr.time.correction_approved" event

    - `GetWorkTimeStatus(ctx, employeeID uuid.UUID) (*WorkTimeStatus, error)`:
      - Convenience method returning: IsClockedIn, IsOnBreak, CurrentShiftStart, CurrentBreakStart, TodayTotalMinutes, ArbZGSeverity
      - Used by the header quick-toggle button for real-time display

    Create `service_test.go` with tests:
    - ClockIn creates active entry, ClockIn twice returns ErrAlreadyClockedIn
    - ClockOut calculates net work minutes and applies auto-break deduction
    - ClockOut with 7h work and no manual break auto-deducts 30min
    - ClockOut with 10h work and 30min manual break auto-deducts 15min (needs 45 total)
    - StartBreak/EndBreak lifecycle
    - Rest period check on clock-in warns if <11h since previous shift
    - ClockIn returns ErrMaxDailyHoursExceeded when today's DailySummary shows >= 600 net minutes (10h block)
    - SubmitTimeCorrection creates correction_pending entry
    - ApproveTimeCorrection transitions status

    **1. Create `backend/internal/server/hr_grpc.go`** -- HRGRPCServer implementing all HRService RPCs.

    Follow the exact same pattern as `biz_grpc.go` (BizGRPCServer):

    ```go
    type HRGRPCServer struct {
        hrv1.UnimplementedHRServiceServer
        leaveService      *leave.Service
        timetrackingService *timetracking.Service
        employeeService   *employee.Service
        absenceService    *absence.Service
        settingsRepo      leave.HRSettingsRepository
    }
    ```

    Implement all ~30 RPCs with proper proto-to-domain and domain-to-proto conversion:
    - Leave RPCs: delegate to leaveService, convert between proto and domain types
    - Time tracking RPCs: delegate to timetrackingService. ClockIn/ClockOut return compliance result alongside entry data.
    - Absence RPCs: delegate to absenceService
    - Employee RPCs: delegate to employeeService
    - Settings RPCs: delegate to settingsRepo (GetByTenant/Upsert)

    Error mapping (same pattern as biz_grpc.go):
    - NotFound errors -> codes.NotFound
    - InvalidTransition/Validation errors -> codes.InvalidArgument
    - Unauthorized errors -> codes.PermissionDenied
    - Default -> codes.Internal

    Use `pageToLimitOffset` helper if it exists from biz_grpc.go, or create a shared one.

    ```go
        r.Use(authMiddleware)
        r.Post("/requests", h.HandleCreateLeaveRequest)

        r.Get("/requests/{id}", h.HandleGetLeaveRequest)
        r.Post("/requests/{id}/approve", h.HandleApproveLeaveRequest)

        r.Post("/requests/{id}/cancel", h.HandleCancelLeaveRequest)
        r.Get("/balance", h.HandleGetLeaveBalance)          // Current user
        r.Get("/balance/{userId}", h.HandleGetEmployeeLeaveBalance)  // Manager view
        r.Get("/types", h.HandleListLeaveTypes)
        r.Post("/sick", h.HandleRecordSickLeave)
    })

    // Time tracking
    r.Route("/api/v1/hr/time", func(r chi.Router) {
        r.Use(authMiddleware)
        r.Post("/clock-in", h.HandleClockIn)
        r.Post("/clock-out", h.HandleClockOut)
        r.Post("/break/start", h.HandleBreakStart)
        r.Post("/break/end", h.HandleBreakEnd)
        r.Get("/active", h.HandleGetActiveShift)
        r.Get("/status", h.HandleGetWorkTimeStatus)
        r.Get("/entries", h.HandleListWorkTimeEntries)
        r.Get("/summary/daily", h.HandleDailySummary)
        r.Get("/summary/weekly", h.HandleWeeklySummary)
        r.Post("/corrections", h.HandleSubmitCorrection)
        r.Post("/corrections/{id}/approve", h.HandleApproveCorrection)
    })

    // Absence calendar
    r.Route("/api/v1/hr/absences", func(r chi.Router) {
        r.Use(authMiddleware)
        r.Get("/calendar", h.HandleGetAbsenceCalendar)
    })

    // Employee profiles
    r.Route("/api/v1/hr/employees", func(r chi.Router) {
        r.Use(authMiddleware)
        r.Get("/", h.HandleListEmployees)
        r.Get("/me", h.HandleGetSelfProfile)
        r.Put("/me", h.HandleUpdateSelfProfile)
        r.Get("/{id}", h.HandleGetEmployee)
        r.Put("/{id}", h.HandleUpdateEmployee)
        r.Get("/{id}/documents", h.HandleListEmployeeDocuments)
        r.Post("/{id}/documents", h.HandleUploadEmployeeDocument)
        r.Get("/{id}/documents/categories", h.HandleListDocumentCategories)
    })

    // HR settings (admin only)
    r.Route("/api/v1/hr/settings", func(r chi.Router) {
        r.Use(authMiddleware)
        r.With(middleware.RequireRole("admin")).Get("/", h.HandleGetHRSettings)
        r.With(middleware.RequireRole("admin")).Put("/", h.HandleUpdateHRSettings)
    })
    ```

    Each handler follows the thin-handler pattern: parse request, extract user/tenant from context, call gRPC, format response. Use `getTenantID` from route_biz.go (same function, imported from the package).
