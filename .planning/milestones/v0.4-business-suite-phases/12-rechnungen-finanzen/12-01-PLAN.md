    Implement the tax calculation engine as a pure function following TDD (RED-GREEN-REFACTOR).

    **RED phase -- write tests first in `calculator_test.go`:**

    Test cases covering all FIN-03 requirements:
    1. **Standard 19% single item:** 1x 100.00 EUR at 19% = net 100.00, tax 19.00, gross 119.00
    2. **Standard 7% reduced rate:** 1x 100.00 EUR at 7% = net 100.00, tax 7.00, gross 107.00
    3. **Mixed rates:** 2 items (one at 19%, one at 7%) -- verify per-rate tax breakdown, subtotal, total tax, gross
    4. **Reverse Charge (0%):** Items with 19% rate but TaxModeReverseCharge = all tax is 0, gross = net
    5. **Kleinunternehmer (0%):** Items with rates but TaxModeKleinunternehmer = all tax is 0, gross = net
    6. **Rounding per line item:** 19% of 123.45 = 23.4555 rounds to 23.46. Verify line-level rounding, not total-level.
    7. **Multiple quantities:** 3x 49.99 at 19% = net 149.97, tax 28.4943 rounds to 28.49, gross 178.46
    8. **Empty line items:** Returns zero breakdown (no panic)
    9. **Zero quantity or zero price:** Line total is 0, tax is 0
    10. **Large values:** 999999.99 EUR at 19% -- no overflow with decimal

    Use `testify/assert` for assertions. Use `decimal.NewFromString("100.00")` for test values (not NewFromFloat to avoid float imprecision in tests).

    **GREEN phase -- implement `calculator.go`:**

    ```go
    package tax

    type TaxMode string
    const (
        ModeStandard        TaxMode = "standard"
        ModeReverseCharge   TaxMode = "reverse_charge"
        ModeKleinunternehmer TaxMode = "kleinunternehmer"
    )

    type LineItem struct {
        Quantity  decimal.Decimal
        UnitPrice decimal.Decimal
        TaxRate   decimal.Decimal // 19.00, 7.00, 0.00
    }

    type Breakdown struct {
        Subtotal   decimal.Decimal
        TaxByRate  map[string]decimal.Decimal // "19.00" -> sum of tax at 19%
        TotalTax   decimal.Decimal
        GrossTotal decimal.Decimal
    }

    func Calculate(items []LineItem, mode TaxMode) Breakdown
    ```

    Implementation rules:
    - Per-line-item rounding to 2 decimal places (Round(2) after each line's tax calculation)
    - For ReverseCharge and Kleinunternehmer: TaxByRate is empty, TotalTax = 0, GrossTotal = Subtotal
    - TaxByRate keys use the rate string (e.g., "19", "7") for grouping
    - All arithmetic uses shopspring/decimal, never float64
    - Function is stateless -- no DB, no side effects, fully deterministic

    Also add helper functions:
    - `RequiresReverseChargeNote(mode TaxMode) bool` -- returns true for ReverseCharge
    - `RequiresKleinunternehmerNote(mode TaxMode) bool` -- returns true for Kleinunternehmer
    - `StandardRate() decimal.Decimal` -- returns 19.00
    - `ReducedRate() decimal.Decimal` -- returns 7.00
