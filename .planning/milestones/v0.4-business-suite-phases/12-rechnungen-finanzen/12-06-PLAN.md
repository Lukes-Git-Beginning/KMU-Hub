4. Implement the 4 RPC methods in `backend/internal/server/biz_grpc.go`. Each method:
   - Parses tenant_id and document id as UUIDs

   - Calls the appropriate `pdfGenerator.Generate*PDF(document)` method
   - Returns the PDF bytes and a German filename (e.g., `Angebot_AG-2024-001.pdf`, `Rechnung_RE-2024-001.pdf`, `Gutschrift_GS-2024-001.pdf`, `Mahnung_MH-2024-001.pdf`)

   Important: The existing `s.pdfGenerator` was initialized at startup with whatever settings were available. For correctness, create a fresh `pdf.NewGenerator(*settings)` per request using the latest company settings from DB. This ensures logo/address changes take effect immediately.

   Look at existing RPC implementations (e.g., GetQuote, GetInvoice) for error handling patterns -- use `status.Error(codes.InvalidArgument, ...)` for bad input, `status.Error(codes.NotFound, ...)` for missing documents, and `status.Error(codes.Internal, ...)` for PDF generation failures.
