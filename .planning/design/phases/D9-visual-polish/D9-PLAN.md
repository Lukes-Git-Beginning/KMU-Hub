# D9: Visual Polish — Plan

## Goal

Finaler Feinschliff: Animationen, Micro-Interactions, Empty States,
Loading States, Accessibility, konsistente UX ueber alle Screens.

## Tasks

### 1. Animations & Transitions
- Profile Switch: fade-in-out + slide-in-right (aus Figma theme.css)
- Dropdown/Modal: smooth open/close
- Navigation: Page transitions
- Desk Maximize: evtl. Scale statt nur Padding
- Deko-Items: gestaffeltes Fade-in beim Restore

### 2. Micro-Interactions
- Button hover/active states konsistent
- Card hover: Shadow + Border-Farbe
- Icon-Translation bei Hover (translate-x-1)
- Live-Meeting: pulsierender roter Dot
- Typing-Indicator: bouncing dots

### 3. Empty States
- Illustrierte Empty-States fuer jedes Modul
- Passend zum Desk-Theme
- Hilfreiche Call-to-Action

### 4. Loading States
- Skeleton-Loader konsistent
- Widget-Loading-States
- Page-Transition-Loading

### 5. Responsive Polish
- Touch-Targets mindestens 44px
- Spacing zwischen interaktiven Elementen
- Text-Wrapping und Overflow

### 6. Accessibility
- Keyboard-Navigation durchgaengig
- Focus-Ring sichtbar (teal, --focus-ring)
- ARIA Labels
- Farbkontrast-Pruefung
