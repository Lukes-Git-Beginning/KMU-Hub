**events/EventPopover.tsx:**
Compact quick-create popover that appears when clicking a time slot (per user decision: click on time slot opens compact popover).

Uses Radix UI Popover. Props:
```typescript
interface EventPopoverProps {
  open: boolean;
  onClose: () => void;
  anchorDate: Date; // the clicked date
  anchorTime: Date; // the clicked time
  anchorRect?: DOMRect; // for positioning
}
```

Content:
- Title input (auto-focused, placeholder "Neuen Termin hinzufuegen")
- Time display/picker: shows selected time range (default 30 min), editable
- Calendar selector: dropdown showing user's calendars (from useCalendars)
- "Mehr Optionen" link: opens EventForm dialog with the entered title and time pre-filled
- "Speichern" button: quick-create with just title + time + default calendar
- "Abbrechen" button or click outside to close
- On save, calls useCreateEvent mutation

Popover positioning: anchor to the clicked time slot element. Use Radix Popover's built-in positioning.

**events/RecurrenceEditor.tsx:**
Recurrence rule editor with presets + custom RRULE (per user decision: presets + custom).

Props:
```typescript
interface RecurrenceEditorProps {
  value: string | null; // current RRULE string or null
  onChange: (rrule: string | null) => void;
  eventStartDate: Date; // needed for BYDAY calculation
}
```

UI:
- Radix Select dropdown with options:
  - "Keine Wiederholung" (null)
  - "Taeglich" (FREQ=DAILY)
  - "Werktags (Mo-Fr)" (FREQ=WEEKLY;BYDAY=MO,TU,WE,TH,FR)
  - "Woechentlich am {currentDayName}" (FREQ=WEEKLY;BYDAY={day})
  - "Alle 2 Wochen am {currentDayName}" (FREQ=WEEKLY;INTERVAL=2;BYDAY={day})
  - "Monatlich am {dayOfMonth}." (FREQ=MONTHLY;BYMONTHDAY={day})
  - "Jaehrlich am {date}" (FREQ=YEARLY;BYMONTH={month};BYMONTHDAY={day})
  - "Benutzerdefiniert..." opens custom editor

- Custom editor panel (shown when "Benutzerdefiniert..." selected):
  - Frequency: Taeglich / Woechentlich / Monatlich / Jaehrlich
  - Interval: "Alle [N] {Tage/Wochen/Monate/Jahre}"
  - For weekly: day checkboxes (Mo, Di, Mi, Do, Fr, Sa, So)
  - For monthly: "Am [N]. Tag" or "Am [1./2./3./4./letzten] [Wochentag]"
  - End condition: "Nie" / "Nach [N] Terminen" (COUNT) / "Am [Datum]" (UNTIL)

- Preview: Show next 3-5 occurrences using rrule npm package for client-side preview:
  ```typescript
  import { RRule } from 'rrule';
  const rule = RRule.fromString(rruleStr);
  const preview = rule.all((_, i) => i < 5);
  ```
  Display dates formatted in German.

Build the RRULE string from the form values. Parse existing RRULE string back into form values when editing.
