**resources/ResourceBookingDialog.tsx:**
Booking form dialog (per user decision: instant booking, first come first served, no approval).

Radix Dialog with:
- Resource name (pre-filled, read-only)
- Date (pre-filled from selected date)
- Start time / End time (pre-filled from clicked slot, editable)
- Event title for the auto-created calendar event
- "Buchen" button

On submit:
1. Call useBookResource mutation with resource_id, start_time, end_time
2. On success: booking confirmed, calendar event auto-created (backend handles this)
3. On conflict (409): Show "Raum belegt" error with alternative room suggestions from the error response. Display alternatives as clickable links that switch to booking that room instead.
4. Invalidate resource availability and calendar event queries

Per user decision: blocked with alternative suggestions on double-booking.

**components/HolidayBadge.tsx:**
Holiday marker displayed in calendar day headers and month view cells (per CAL-07: DACH public holidays per Bundesland/Kanton).

Props:
```typescript
interface HolidayBadgeProps {
  holidays: PublicHoliday[];
}
```

UI:
- Small colored badge (pastel red/orange background) showing holiday name
- If multiple holidays for a day (rare), show first with "+N" indicator
- Tooltip on hover shows full holiday name (local_name for DACH context)
- Displayed in:
  - Week view day headers (above the day number)
  - Day view header
  - Month view cells (as a colored bar above events)

Integration point: The views (WeekView, DayView, MonthView) need to:
1. Get user's subdivision_code from useCalendarPreferences
2. Fetch holidays via useHolidays(year, countryCode, subdivisionCode)
3. Match holidays to displayed dates
4. Render HolidayBadge in the appropriate header/cell

The countryCode is derived from subdivisionCode (e.g., "DE-BY" -> "DE", "CH-ZH" -> "CH").

Update WeekView, DayView, MonthView to integrate holidays:
- WeekView: show HolidayBadge in day header row below day name
- DayView: show HolidayBadge next to date header
- MonthView: show HolidayBadge as colored bar in cell

If subdivisionCode is not set in preferences, holidays are not shown (user needs to configure their Bundesland/Kanton in calendar preferences).
