**utils/eventLayout.ts:**
Implement the greedy column-packing algorithm for overlapping events (per RESEARCH.md):

```typescript
interface LayoutEvent {
  id: string;
  startMinutes: number; // minutes from midnight
  endMinutes: number;
  calendarId: string;
}

interface PositionedEvent extends LayoutEvent {
  columnIndex: number;
  columnCount: number;
}

export function computeEventColumns(events: LayoutEvent[]): PositionedEvent[]
```

Algorithm:
1. Sort events by startMinutes ascending, then by duration descending (longest first)
2. Initialize empty columns: `columns: LayoutEvent[][]`
3. For each event, find first column where it doesn't overlap with any existing event
4. If no column is free, create a new column
5. Place the event in that column
6. After all events placed, for each event set columnCount = total columns that overlap with its time range (not global total -- this gives better space distribution)

This is O(n*k) where n = events, k = max columns. Handles the side-by-side display for overlapping events from different calendars.
