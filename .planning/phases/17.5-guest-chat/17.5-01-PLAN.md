        ID             uuid.UUID  `json:"id"`

    **postgres_repository.go** -- Full pgx implementation:
    - Constructor: `NewPostgresRepository(pool *pgxpool.Pool) *PostgresRepository`
    - All methods use parameterized queries ($1, $2...)
    - GetSessionByTokenHash: SELECT with JOIN on channels to verify is_guest_enabled, checks expires_at > NOW() and is_active
    - CreateSession: INSERT with RETURNING (all fields)
    - CleanupExpiredSessions: UPDATE SET is_active=false WHERE expires_at < NOW() AND is_active=true, return count
    - IncrementFailedValidations: Use in-memory map with sync.Mutex (not DB -- ephemeral tracking)
    - GetConfigByChannel: SELECT with channel_id FK

    **service.go** -- Guest session lifecycle:
    ```go
    type Service struct {
        repo        Repository
        rateLimiter *GuestRateLimiter
    }

    func NewService(repo Repository) *Service
    ```

    Methods:
    - `CreateSession(ctx, input CreateSessionInput) (*TokenResult, error)`:
      1. Validate display_name (required, max 200 chars)
      2. Generate UUID v4 token
      3. Hash token with SHA-256 for storage
      4. Get channel config for expiry duration (or default 168h)
      5. Create GuestSession with token_hash, channel_id, expires_at=now+expiry
      6. Return TokenResult with plain token (only returned once)

    - `ValidateToken(ctx, token string) (*GuestSession, error)`:
      1. SHA-256 hash the token
      2. Lookup by token_hash
      3. Check is_active and expires_at > now
      4. Update last_activity_at
      5. Return session or error

    - `DeactivateSession(ctx, sessionID uuid.UUID) error`:
      Mark session inactive (agent abuse-reporting)

    - `CleanupExpired(ctx) (int, error)`:
      Delegate to repo.CleanupExpiredSessions

    - `CreateConfig(ctx, input CreateConfigInput) (*GuestChannelConfig, error)`:
      Create guest channel config with defaults for nil fields

    - `GetConfig(ctx, channelID uuid.UUID) (*GuestChannelConfig, error)`:
      Get config, return ErrConfigNotFound if not exists

    - `UpdateConfig(ctx, config *GuestChannelConfig) error`:
      Update existing config

    - `CheckRateLimit(sessionID uuid.UUID) error`:
      Delegate to rate limiter, return ErrRateLimited if exceeded

    **rate_limiter.go** -- Sliding window rate limiter:
    ```go
    type GuestRateLimiter struct {
        mu      sync.Mutex
        windows map[string][]time.Time // session_id -> timestamps of recent messages
        limit   int                     // max messages per window (default 30)
        window  time.Duration           // window duration (default 1 minute)
    }

    func NewGuestRateLimiter(limit int, window time.Duration) *GuestRateLimiter
    ```

    - `Allow(sessionID string) bool`: Add current timestamp, prune old entries outside window, check count < limit
    - Cleanup stale entries on every Allow() call (prune timestamps older than window)
    - No persistence needed -- in-memory is fine, resets on gateway restart
