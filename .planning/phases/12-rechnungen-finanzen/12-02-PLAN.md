    **Service (`service.go`):**

    Constructor: `NewService(repo Repository, taxCalc *tax.Calculator, numberSeqRepo NumberSequenceRepo, companySettingsRepo CompanySettingsRepo, dealUpdater DealValueUpdater)` where `DealValueUpdater` is a small interface:

    ```go
    // DealValueUpdater updates the CRM deal value. Implemented by a thin wrapper
    // around the CRM gRPC client. Nil-safe: if nil, sync is skipped (standalone mode).
    type DealValueUpdater interface {
        UpdateDealValue(ctx context.Context, dealID uuid.UUID, grossTotal decimal.Decimal) error
    }
    ```

    This interface will be implemented in the gRPC server layer (Plan 04) as a wrapper around the CRM gRPC client's UpdateDeal RPC. The quote service calls it but does not depend on gRPC directly.

    Service methods:
    - `Create(ctx, input CreateInput) (*models.Quote, error)` -- validates line items non-empty, calls tax.Calculate(), stores results, sets valid_until from company_settings default_quote_validity_days. **After successful creation, if deal_id is set and dealUpdater is not nil, call dealUpdater.UpdateDealValue(ctx, *input.DealID, breakdown.GrossTotal) to sync the quote gross_total back to the CRM deal (locked decision: deal value auto-syncs). Log warning on sync failure but do not fail the quote creation (graceful degradation).** CreateInput has: CustomerName, CustomerAddress, CustomerEmail, CustomerUstIDNr, TaxMode, LineItems []models.LineItem, ValidUntil *time.Time, Notes, DealID *uuid.UUID, UserID.
    - `GetByID(ctx, id) (*models.Quote, error)`
    - `List(ctx, filter ListFilter) ([]*models.Quote, int, error)` -- ListFilter: Status, DealID, DateFrom, DateTo, Limit, Offset.
    - `Update(ctx, id, input UpdateInput) (*models.Quote, error)` -- only if status=draft. Recalculates tax. **After successful update, if the quote has a deal_id and dealUpdater is not nil, call dealUpdater.UpdateDealValue(ctx, dealID, breakdown.GrossTotal) to re-sync the deal value (locked decision: auto-syncs on modification). Log warning on sync failure but do not fail the update.**
    - `Delete(ctx, id) error` -- only if status=draft.
    - `Send(ctx, id, userID) error` -- transitions draft->sent, assigns quote number via NextNumber (prefix "AN", e.g., AN-2026-0001). Uses the same number sequence pattern as invoices.
    - `Accept(ctx, id) error` -- sent->accepted
    - `Reject(ctx, id) error` -- sent->rejected
    - `ExpireQuotes(ctx) (int, error)` -- bulk update: all sent quotes past valid_until -> expired

    Design note (Claude's discretion): Quote -> deal sync is unidirectional. The deal value reflects the latest quote gross_total. Editing the deal value directly in CRM does not affect quotes. This is the simplest model and avoids circular sync loops.

    Errors: ErrQuoteNotFound, ErrQuoteNotDraft, ErrQuoteNotSent, ErrNoLineItems.

  <action>
    Create the invoice service package following the established repository pattern.

    **Repository interface (`repository.go`):**

    Methods: Create, GetByID, List, Update, SendInvoice (sets number, snapshot, status), UpdateStatus, NextInvoiceNumber (gap-free via FOR UPDATE on finance_number_sequences), GetOverdue, GetByQuoteID.

    **NextInvoiceNumber implementation (CRITICAL for GoBD) in `postgres_repository.go`:**

    ```sql
    BEGIN;
    SELECT current_number FROM finance_number_sequences
      WHERE tenant_id = $1 AND document_type = 'invoice' AND fiscal_year = $2
      FOR UPDATE;
    UPDATE finance_number_sequences SET current_number = current_number + 1
      WHERE tenant_id = $1 AND document_type = 'invoice' AND fiscal_year = $2;
    COMMIT;
    -- Returns: RE-{year}-{padded_number} e.g., RE-2026-0001
    ```
    If no sequence row exists for the fiscal year, INSERT it with current_number=1 within the same transaction.

    **PostgresRepository (`postgres_repository.go`):**

    Standard pgx implementation. Uses JSONB for line_items, tax_breakdown, snapshot_data, company_snapshot. List supports filtering by tenant_id + optional status, date range, overdue flag.

    **Service (`service.go`):**

    Constructor: `NewService(repo Repository, taxCalc, numberSeqRepo, companySettingsRepo)`

    Methods:
    - `Create(ctx, input CreateInput) (*models.Invoice, error)` -- validates, calculates tax, sets due_date from payment terms. CreateInput: CustomerName/Address/Email/UstIDNr, TaxMode, LineItems, InvoiceDate, DeliveryDate, PaymentTermsDays, Notes, SourceQuoteID, UserID.
    - `GetByID(ctx, id) (*models.Invoice, error)`
    - `List(ctx, filter) ([]*models.Invoice, int, error)` -- filter by status, date range, overdue flag.
    - `Update(ctx, id, input) (*models.Invoice, error)` -- ONLY if status=draft. Recalculates tax. If status != draft, return ErrInvoiceImmutable (GoBD enforcement).
    - `Send(ctx, id, userID, companySettings) error` -- transitions draft->sent. Assigns sequential number. Builds complete snapshot (line items, tax breakdown, customer data, company data) as JSONB. Sets invoice_date if not set. After this, the invoice is IMMUTABLE.
    - `MarkPaid(ctx, id) error` -- sent/overdue->paid. Sets status to paid.
    - `Cancel(ctx, id, userID) error` -- draft/sent->cancelled. Cannot cancel paid invoices.
    - `DetectOverdue(ctx) (int, error)` -- bulk: all sent invoices past due_date -> overdue.
    - `CreateFromQuote(ctx, quoteID, userID) (*models.Invoice, error)` -- copy-and-link: reads quote, creates invoice with source_quote_id set, copies line items and customer data. Quote status must be "accepted". This is the quote-to-invoice conversion per user decision (copy-and-link pattern).

    Errors: ErrInvoiceNotFound, ErrInvoiceImmutable, ErrInvoiceNotDraft, ErrInvoiceAlreadyPaid, ErrInvoiceAlreadyCancelled.
  </action>
