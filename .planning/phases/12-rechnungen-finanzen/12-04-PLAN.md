    `mapping.go` -- SKR03 account mapping per research discretion recommendation:
    - Revenue 19%: account 8400 (Erloese 19% USt)
    - Revenue 7%: account 8300 (Erloese 7% USt)
    - Revenue 0% (EU): account 8125 (steuerfreie innergemeinschaftliche Lieferungen)
    - Revenue 0% (Kleinunternehmer): account 8195 (steuerfreie Umsaetze Inland)
    - Debitor accounts: 10000+ range (auto-generated per customer, using customer index)
    - BU-Schluessel: 3 for 19% USt, 2 for 7% USt, empty for 0%
    - Define as Go constants/maps.

    `exporter.go`:
    - `type Exporter struct` with fiscal year config
    - `NewExporter() *Exporter`
    - `Export(invoices []*models.Invoice, creditNotes []*models.CreditNote, fiscalYearStart time.Time, generatedAt time.Time) ([]byte, error)` -- returns CSV bytes

    CSV generation using `encoding/csv` with semicolon delimiter (`csv.Writer` with `Comma = ';'`):
    1. Write EXTF header line (line 1) per research code example -- format version 700, data category 21, "Buchungsstapel", format version 13, timestamp, source "KMU Hub", fiscal year start, account length 4.
    2. Write column header line (line 2): Umsatz (ohne Soll/Haben-Kz), Soll/Haben-Kennzeichen, WKZ Umsatz, Kurs, Basis-Umsatz, WKZ Basis-Umsatz, Konto, Gegenkonto (ohne BU-Schluessel), BU-Schluessel, Belegdatum, Belegfeld 1, Belegfeld 2, Skonto, Buchungstext, ...
    3. For each invoice (status=sent/paid/overdue): create booking records. Each line item becomes a booking line:
       - Umsatz: gross amount of line (net + tax)
       - S/H: "S" (Soll = debit) for revenue bookings
       - WKZ: "EUR"
       - Konto: debitor account (10000 + customer index)
       - Gegenkonto: revenue account (8400/8300/8125 based on tax rate)
       - BU-Schluessel: 3/2/empty based on rate
       - Belegdatum: invoice_date as DDMM (4 digits, no separator)
       - Belegfeld 1: invoice_number
       - Buchungstext: line item description (truncated to 60 chars)
    4. For credit notes: same pattern but with "H" (Haben = credit) and negative amounts.

    Encoding: UTF-8 with BOM (write `\xEF\xBB\xBF` prefix) for DATEV compatibility.

       ```go
       // crmDealUpdater implements quote.DealValueUpdater by calling CRM UpdateDeal RPC.
       type crmDealUpdater struct {
           crmClient crmv1.CRMServiceClient
       }

       func (u *crmDealUpdater) UpdateDealValue(ctx context.Context, dealID uuid.UUID, grossTotal decimal.Decimal) error {
           _, err := u.crmClient.UpdateDeal(ctx, &crmv1.UpdateDealRequest{
               Id:    dealID.String(),
               Value: grossTotal.String(),
           })
           return err
       }
       ```

       This fulfills the locked decision: "Deal value auto-syncs when quote is created or modified." The sync direction is quote -> deal (Claude's discretion).
