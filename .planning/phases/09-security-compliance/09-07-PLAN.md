  <action>
    1. Install dependencies:
       ```bash
       cd desktop
       npm install react-intl @formatjs/cli
       ```

    2. Create `stores/locale.ts` (Zustand store with persistence, follow existing store patterns):
       ```typescript
       interface LocaleState {
         locale: string | null  // null = auto-detect
         setLocale: (locale: string) => void
         resetLocale: () => void  // back to auto-detect
       }
       ```
       Persist to localStorage with key 'locale-store'. Available locales as const: ['de', 'en', 'fr', 'it'].

    3. Create `i18n/formats.ts` with locale-specific format configurations:
       - Date formats per locale (short, medium, long) using Intl.DateTimeFormat options
       - Number formats per locale (decimal, currency CHF/EUR)
       - Currency display settings (symbol for CHF/EUR)
       - Example: `{ de: { date: { short: { day: '2-digit', month: '2-digit', year: 'numeric' } } } }`
       - Export a `getFormats(locale: string)` function that returns the format config for react-intl's `formats` prop.

    4. Create `hooks/useLocale.ts`:
       - `useLocale()` hook that returns:
         - `locale`: current effective locale (from store, or browser-detected, or 'de' fallback)
         - `setLocale(locale: string)`: updates store
         - `resetToAuto()`: clears store, reverts to browser detection
         - `availableLocales`: array of {code, name} objects (de: 'Deutsch', en: 'English', fr: 'Francais', it: 'Italiano')
         - `isAutoDetected`: boolean, true if store locale is null
       - Browser detection logic: `navigator.language.split('-')[0]`, check if in supported list, fallback to 'de'.

    5. Create `i18n/index.tsx`:
       - `I18nProvider` component that wraps children in react-intl's `IntlProvider`
       - Imports all message files (de, en, fr, it)
       - Uses `useLocale()` hook to get effective locale
       - Passes locale, messages, defaultLocale='de', formats from getFormats()
       - `onError` handler: suppress MISSING_TRANSLATION in development, log others
       - Export the provider component

    Use per user decision: react-intl (not i18next). Locale persistence is per-user in Zustand/localStorage, not org-level.
  </action>
  <verify>
    - `cd desktop && npx tsc --noEmit` compiles without errors
    - package.json includes react-intl and @formatjs/cli
    - i18n/index.tsx exports I18nProvider
    - stores/locale.ts exports useLocaleStore
    - hooks/useLocale.ts exports useLocale
  </verify>
  <done>i18n infrastructure: react-intl IntlProvider, Zustand locale store with persistence, browser detection with fallback chain (user -> browser -> DE), useLocale hook.</done>
