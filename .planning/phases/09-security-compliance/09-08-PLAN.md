       - Audit endpoints: listAuditEntries(filter), exportAuditLog(filter, format), verifyAuditChain(fromSeq, toSeq)
       - Vault endpoints: listVaultSecrets, getVaultSecret(keyName), setVaultSecret(keyName, value, description), deleteVaultSecret(keyName)

       - IP rule endpoints: listIPRules, createIPRule, deleteIPRule

       - `useDisable2FA()` -- useMutation calling disable2FA, invalidates auth queries
       - `useRegenerateRecoveryCodes()` -- useMutation
       - `useAdminReset2FA()` -- useMutation
       - `useTwoFactorPolicies()` -- useQuery for listing policies
       - `useUpdateTwoFactorPolicy()` -- useMutation, invalidates policies query

       - `useTerminateSession()` -- useMutation, invalidates sessions queries
       - `useTerminateAllSessions()` -- useMutation, invalidates sessions queries

    5. Create `hooks/useSecurity.ts`:
       - `useAuditLog(filter)` -- useQuery with filter as query key, returns paginated entries
       - `useExportAuditLog()` -- useMutation that triggers download (creates blob URL)
       - `useVerifyAuditChain()` -- useMutation
       - `useVaultSecrets()` -- useQuery listing secrets (metadata only)
       - `useGetVaultSecret()` -- useMutation (not query, to avoid caching decrypted values)
       - `useSetVaultSecret()` -- useMutation, invalidates vault query

       - `useRequestExport()` -- useMutation
       - `useApproveExport()` -- useMutation
       - `useDenyExport()` -- useMutation
       - `usePasswordPolicy()` -- useQuery

       - `useValidatePassword()` -- useMutation (real-time validation feedback)

       - Step 3: Verification -- text input for 6-digit TOTP code, "Verify" button. Calls useVerify2FA mutation.
       - Step 4: Recovery Codes -- display 8 codes in a grid, "Download as text file" button (creates .txt blob), "Copy to clipboard" button. "Done" button closes wizard.

       Use Radix Dialog for the modal. Use react-intl FormattedMessage for all text. Include error handling with toast notifications (sonner). Step indicator (1/4, 2/4, etc.) at top.

       Also add a "Regenerate Recovery Codes" section (separate from wizard) that shows when 2FA is already enabled. And a "Disable 2FA" button with confirmation dialog.

    2. Create `modules/security/AuditLogPage.tsx`:
       Searchable/filterable table per user decision:
       - Columns: Timestamp (FormattedDate), User, Action, Target, IP Address, Result (badge: green/red)
       - Filter bar: date range picker, action type dropdown, user search, result dropdown (all/success/failure)
       - Pagination controls (offset/limit)
       - Export buttons: "CSV" and "JSON" (trigger download via blob URL)
       - "Verify Integrity" button (calls verifyAuditChain, shows toast with result)

       Use Tailwind for styling. Use existing table patterns from the project. Use react-intl for all visible text.

    3. Create `modules/security/SessionsPage.tsx`:

       - "Terminate" button per session (with confirmation dialog)
       - "Terminate All Others" button at top
       - Admin view: toggle to show all users' sessions (uses useAllSessions)

       Use Tailwind cards for each session. Use react-intl FormattedMessage.

    4. Create `modules/security/VaultPage.tsx`:
       Admin-only page:

       - "Add Secret" dialog (key name, value, description inputs)
       - "Edit" button (update value/description)
