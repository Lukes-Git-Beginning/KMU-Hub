  <action>
    1. Create `models.go` with audit action constants:
       - Security: ActionLogin, ActionLogout, ActionLoginFailed, Action2FAEnabled, Action2FADisabled, Action2FAAdminReset, ActionPasswordChanged, ActionRoleChanged, ActionSessionTerminated
       - Admin: ActionUserInvited, ActionUserDeactivated, ActionSettingsChanged, ActionVaultAccess, ActionEnforcementPolicyChanged
       - Data: ActionSensitiveDataViewed, ActionBulkDataExport, ActionDataExportRequested, ActionDataExportApproved, ActionDataDeletionExecuted
       - Results: ResultSuccess = "success", ResultFailure = "failure"
       - Audit advisory lock ID constant: `AuditLockID int64 = 8675309` (arbitrary stable int for pg_advisory_xact_lock)

    2. Create `repository.go` with Repository interface:
       - `Create(ctx context.Context, entry *models.AuditEntry) error` -- writes with hash chaining
       - `List(ctx context.Context, filter *models.AuditFilter) ([]*models.AuditEntry, int, error)` -- returns entries + total count for pagination
       - `GetLastHash(ctx context.Context) (string, error)` -- returns hash of most recent entry
       - `VerifyChain(ctx context.Context, fromSequence, toSequence int64) (bool, int64, error)` -- verifies hash chain integrity, returns (valid, first_broken_sequence, error)
       - `GetRetentionCutoff(ctx context.Context) (time.Time, error)` -- for cleanup

    3. Create `postgres_repository.go`:
       - `Create`: BEGIN tx, pg_advisory_xact_lock(AuditLockID), SELECT entry_hash FROM audit_log ORDER BY sequence_num DESC LIMIT 1, compute new entry hash, INSERT, COMMIT. This serializes all audit writes to prevent hash chain breaks.
       - `computeEntryHash(entry *models.AuditEntry, previousHash string) string`: SHA-256 of timestamp|user_id|action|target|details|ip_address|result|previousHash. Use `crypto/sha256` + `encoding/hex`.
       - `List`: Dynamic query builder with optional WHERE clauses for each filter field. Support: date_from (>=), date_to (<=), user_id (=), action (=), result (=). ORDER BY sequence_num DESC. LIMIT/OFFSET for pagination. Also execute COUNT(*) with same filters for total.
       - `VerifyChain`: SELECT entries in sequence order, recompute each hash and compare. Return first broken link if any.

    4. Create `service.go`:
       - `type Service struct { repo Repository }` + `NewService(repo Repository) *Service`
       - `LogEvent(ctx context.Context, userID uuid.UUID, action, target, targetType string, details map[string]interface{}, ipAddress, userAgent, result string) error` -- marshals details to JSON, creates AuditEntry, calls repo.Create. Never returns error to caller (log error internally with slog) -- audit failures must not block business operations.
       - `ListEntries(ctx context.Context, filter *models.AuditFilter) ([]*models.AuditEntry, int, error)` -- delegates to repo.
       - `VerifyChainIntegrity(ctx context.Context, fromSequence, toSequence int64) (bool, int64, error)` -- delegates to repo.
       - `ExportEntries(ctx context.Context, filter *models.AuditFilter, format string) ([]byte, error)` -- fetches all matching entries (no pagination), delegates to export functions.

    5. Create `export.go`:
       - `ExportCSV(entries []*models.AuditEntry) ([]byte, error)` -- uses encoding/csv. Columns: Timestamp, User ID, Action, Target, Target Type, IP Address, Result, Details (JSON string). RFC 4180 compliant with UTF-8 BOM for Excel compatibility.
       - `ExportJSON(entries []*models.AuditEntry) ([]byte, error)` -- marshals to indented JSON array.

    Use structured logging (slog) throughout. LogEvent must NEVER panic or return errors that block the calling operation.
