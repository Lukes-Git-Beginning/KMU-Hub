    4. Create `backend/internal/auth/totp.go` with 2FA service methods on the existing Service struct. The Service needs a reference to the vault service for TOTP encryption -- add a `SetVaultService(vaultSvc VaultEncryptor)` method or accept it in constructor. Define interface `VaultEncryptor` with `EncryptTOTPSecret(secret string) (string, error)` and `DecryptTOTPSecret(encrypted string) (string, error)` to avoid hard dependency on vault package.

       Methods:
       - `func (s *Service) Setup2FA(ctx context.Context, userID uuid.UUID) (*models.TwoFactorSetup, error)`:
         a. Get user, check not already enabled
         b. Generate TOTP key with `totp.Generate(totp.GenerateOpts{Issuer: "KMU Hub", AccountName: user.Email, Algorithm: otp.AlgorithmSHA1})`
         c. Generate QR code PNG using key.Image(200, 200) + png.Encode
         d. Encrypt secret using VaultEncryptor.EncryptTOTPSecret
         e. Store pending secret via repo.StorePending2FASecret
         f. Return TwoFactorSetup{QRCodePNG, ManualSecret: key.Secret()}

       - `func (s *Service) Verify2FA(ctx context.Context, userID uuid.UUID, code string) ([]string, error)`:
         a. Get pending secret, decrypt
         b. Validate code with totp.Validate(code, secret)
         c. Generate 8 recovery codes (10 hex chars each, crypto/rand)
         d. Hash each code with SHA-256
         e. Enable 2FA via repo.Enable2FA
         f. Return plaintext recovery codes (shown once to user)

       - `func (s *Service) Validate2FALogin(ctx context.Context, userID uuid.UUID, code string, isRecoveryCode bool) error`:
         a. Get user, verify 2FA is enabled
         b. If isRecoveryCode: find unused recovery code matching hash, mark as used
         c. If TOTP code: decrypt secret, validate with totp.Validate
         d. Return nil on success, appropriate error on failure

       - `func (s *Service) Disable2FA(ctx context.Context, userID uuid.UUID) error`:
         Calls repo.Disable2FA

       - `func (s *Service) RegenerateRecoveryCodes(ctx context.Context, userID uuid.UUID) ([]string, error)`:
         Generate 8 new codes, hash them, replace via repo.ReplaceRecoveryCodes, return plaintext codes

       - `func (s *Service) AdminReset2FA(ctx context.Context, targetUserID uuid.UUID, reason string) error`:
         Validate reason is non-empty, call repo.Disable2FA. The audit log entry is created by the gateway/caller (not here).

       - `func (s *Service) GetTwoFactorPolicy(ctx context.Context, roleName string) (*models.TwoFactorPolicy, error)`:
         Delegates to repo.

       - `func (s *Service) UpdateTwoFactorPolicy(ctx context.Context, policy *models.TwoFactorPolicy) error`:
         Delegates to repo.UpsertTwoFactorPolicy.

       - `func (s *Service) Check2FAEnforcement(ctx context.Context, userID uuid.UUID) (required bool, graceDaysRemaining int, err error)`:
         Get user's roles, check policies for each role. If any role is enforced and user doesn't have 2FA enabled, check grace period. If grace period expired, return required=true with 0 days. If within grace, return required=false with remaining days.

       Helper: `generateRecoveryCodes(count int) []string` -- generates count random hex codes (10 chars each).
       Helper: `hashRecoveryCode(code string) string` -- SHA-256 hex-encoded hash.

       - Add `func (tm *TokenMaker) CreatePendingToken(userID uuid.UUID) (string, error)` -- creates a JWT with PendingClaims, 5-minute expiry, and a "type":"2fa_pending" custom claim.
       - Add `func (tm *TokenMaker) ValidatePendingToken(tokenStr string) (uuid.UUID, error)` -- parses the JWT, verifies "type":"2fa_pending" claim, returns userID.

    2. Modify `backend/internal/auth/service.go` Login method:
       - After successful credential validation (existing code), check if user.TwoFactorEnabled is true.
       - If 2FA enabled: create a pending token via tokenMaker.CreatePendingToken(user.ID). Return a LoginResult with RequiresTwoFactor=true and PendingToken set. Do NOT create access/refresh tokens.
       - If 2FA not enabled: proceed as before (create token pair, return LoginResult with tokens).
       - Add models.LoginResult struct if not already in models/security.go. It should have: User *models.User, Tokens *models.TokenPair, RequiresTwoFactor bool, PendingToken string.

    3. Add new method `func (s *Service) CompleteTwoFactorLogin(ctx context.Context, pendingToken, code string, isRecoveryCode bool) (*models.User, *models.TokenPair, error)`:
       - Validate pending token to get userID
       - Call Validate2FALogin(ctx, userID, code, isRecoveryCode)
       - If valid: create full token pair, return user + tokens
       - If invalid: return appropriate error

    4. After successful login with 2FA enforcement check: if Check2FAEnforcement returns required=true and grace expired, return an error indicating 2FA setup is required before login is allowed. The user must set up 2FA first. This prevents bypassing enforcement.

    Keep the existing Login method signature compatible -- use the new LoginResult type to convey both normal and 2FA-pending outcomes.
