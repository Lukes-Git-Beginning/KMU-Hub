```go
type Repository interface {
    Create(ctx context.Context, folder *models.DocumentFolder) error
    GetByID(ctx context.Context, id uuid.UUID) (*models.DocumentFolder, error)
    List(ctx context.Context, filter ListFilter) ([]*models.DocumentFolder, int, error)
    Update(ctx context.Context, id uuid.UUID, input UpdateInput) error
    Delete(ctx context.Context, id uuid.UUID) error
    GetPath(ctx context.Context, id uuid.UUID) ([]models.FolderPathSegment, error)
    GetChildren(ctx context.Context, parentID uuid.UUID) ([]*models.DocumentFolder, error)
    CountFiles(ctx context.Context, folderID uuid.UUID) (int, error)
    IsDescendant(ctx context.Context, folderID, potentialAncestorID uuid.UUID) (bool, error)
}

type ListFilter struct {
    ParentID  *uuid.UUID
    SpaceType *string
    SpaceID   *uuid.UUID
}

type UpdateInput struct {
    Name     *string
    ParentID *uuid.UUID
    Icon     *string
}
```

**postgres_repository.go:** Implement all Repository methods using pgx:
- `GetPath`: Use recursive CTE to walk up from folder to root, return breadcrumb segments in root-first order.
- `List`: Filter by parent_id, space_type, space_id. Order by is_system DESC (system folders first), then name ASC. Include file_count via subquery.
- `IsDescendant`: Recursive CTE to check if folderID is a descendant of potentialAncestorID (for preventing circular moves).
- `Delete`: Also delete all files in folder (cascade handles via FK, but soft-delete files first).

**service.go:** Define Service struct and methods:
```go
type Service struct {
    repo Repository
}

func NewService(repo Repository) *Service
```

Methods:
- `Create(ctx, input CreateInput) (*models.DocumentFolder, error)` — validate name (1-255 chars), validate space_type is valid enum, check parent exists if provided, check no duplicate name in same parent, insert.
- `GetByID(ctx, id) (*models.DocumentFolder, error)`
- `List(ctx, filter ListFilter) ([]*models.DocumentFolder, int, error)`
- `Update(ctx, id, input UpdateInput) error` — validate new name if changed, check not system folder for rename, check circular parent if moving (use IsDescendant).
- `Delete(ctx, id) error` — check not system folder, delete.
- `GetPath(ctx, id) ([]models.FolderPathSegment, error)` — returns root-first breadcrumb path.
- `InitializeUserSpace(ctx, userID) error` — create personal root folder + 3 default subfolders: "Dokumente", "Bilder", "Vorlagen" (all with is_system=true).
- `InitializeTeamSpace(ctx, teamID, teamName) error` — create team root folder + 3 default subfolders: "Allgemein", "Projekte", "Vorlagen" (all with is_system=true).

Use structured logging (slog) for all error cases and significant operations.

Methods:

- `ListVersions(ctx, fileID) ([]*models.DocumentFileVersion, error)`
- `RevertVersion(ctx, fileID, versionNumber, userID) (*models.DocumentFileVersion, error)` — get version's storage_key, copy MinIO object to new version key, create new version record (revert = create new latest version with old content).
