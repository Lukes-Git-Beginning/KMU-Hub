    Create `errors.go` with domain errors:
    - ErrLeaveRequestNotFound, ErrInvalidTransition, ErrInsufficientBalance, ErrOverlappingApproved, ErrCannotApproveOwnRequest, ErrAUDocumentRequired, ErrNotAuthorizedToApprove

    Create `repository.go` with interfaces:

    ```go
    type LeaveRequestRepository interface {
        Create(ctx context.Context, req *models.LeaveRequest) error
        GetByID(ctx context.Context, id uuid.UUID) (*models.LeaveRequest, error)
        List(ctx context.Context, filter LeaveRequestFilter) ([]*models.LeaveRequest, int, error)
        Update(ctx context.Context, req *models.LeaveRequest) error
        FindOverlaps(ctx context.Context, employeeID uuid.UUID, startDate, endDate time.Time, excludeID *uuid.UUID) ([]*models.LeaveRequest, error)
    }

    type LeaveBalanceRepository interface {
        GetByEmployeeYear(ctx context.Context, tenantID, employeeID uuid.UUID, year int) (*models.LeaveBalance, error)
        Upsert(ctx context.Context, balance *models.LeaveBalance) error
    }

    type LeaveTypeRepository interface {
        ListByTenant(ctx context.Context, tenantID uuid.UUID) ([]*models.LeaveType, error)
        GetByID(ctx context.Context, id uuid.UUID) (*models.LeaveType, error)
    }

    type HRSettingsRepository interface {
        GetByTenant(ctx context.Context, tenantID uuid.UUID) (*models.HRCompanySettings, error)
        Upsert(ctx context.Context, settings *models.HRCompanySettings) error
    }
    ```

    `LeaveRequestFilter` struct with optional fields: TenantID, EmployeeID, Status, StartDateFrom, StartDateTo, Page, PerPage.

    Create `postgres_repository.go` implementing all repository interfaces with pgx queries.
    - `FindOverlaps` query: SELECT where employee_id = $1 AND status IN ('pending', 'approved') AND daterange(start_date, end_date, '[]') && daterange($2, $3, '[]') AND ($4::uuid IS NULL OR id != $4)
    - List with pagination: LIMIT/OFFSET with total count via COUNT(*) OVER()

    Create `service.go` with `Service` struct:

    ```go
    type Service struct {
        leaveRepo     LeaveRequestRepository
        balanceRepo   LeaveBalanceRepository
        typeRepo      LeaveTypeRepository
        settingsRepo  HRSettingsRepository
        employeeRepo  employee.EmployeeRepository  // For manager lookup
        pool          *pgxpool.Pool                 // For event emission
    }
    ```

    Service methods:

    - `CreateLeaveRequest(ctx, tenantID, employeeID uuid.UUID, input CreateLeaveInput) (*models.LeaveRequest, error)`:
      - Validate dates (end >= start)
      - Calculate total_days considering half-day flags (each half-day = 0.5 off the total)
      - Look up leave type to check if it deducts from balance
      - If deducts: calculate current balance via compliance.CalculateLeaveBalance, check sufficient remaining
      - If leave type is "krank": check AU threshold from settings, set au_document_required if duration >= threshold
      - Set status = "pending" (or skip if leave type doesn't require approval, e.g., sick leave)
      - For sick leave (requires_approval=false): auto-approve and set status = "approved"
      - Emit "hr.leave.requested" event to notify manager (or "hr.leave.approved" for auto-approved sick leave)

    - `ApproveLeaveRequest(ctx, requestID, approverID uuid.UUID, comment string) error`:
      - Validate current status is "pending"
      - Verify approver is the employee's manager OR has "hr" role (HR fallback) -- per locked decision
      - Prevent self-approval (approverID != employeeID)
      - Check overlaps and include overlap info in response (warn but allow -- per locked decision)
      - Transition to "approved", set approved_by, approved_at, approval_comment
      - Update leave balance: increment used days
      - Emit "hr.leave.approved" event to employee

    - `RejectLeaveRequest(ctx, requestID, approverID uuid.UUID, comment string) error`:
      - Same authorization as approve
      - Transition to "rejected"
      - Emit "hr.leave.rejected" event

    - `CancelLeaveRequest(ctx, requestID, employeeID uuid.UUID) error`:
      - Only employee can cancel their own request
      - Can cancel "pending" or "approved" (before start date) -- per state machine
      - If was "approved" and deducted balance: restore balance
      - Transition to "cancelled"
      - Emit "hr.leave.cancelled" event

    - `GetLeaveBalance(ctx, tenantID, employeeID uuid.UUID) (*models.LeaveBalance, error)`:
      - Get employee profile for contract info
      - Get or create balance record for current year
      - Use compliance.CalculateLeaveBalance to compute live balance
      - Return balance with carryover deadline and expiry status

    - `ListLeaveRequests(ctx, filter LeaveRequestFilter) ([]*models.LeaveRequest, int, error)`: delegate to repo
    - `GetLeaveRequest(ctx, id uuid.UUID) (*models.LeaveRequest, error)`: delegate to repo
    - `ListLeaveTypes(ctx, tenantID uuid.UUID) ([]*models.LeaveType, error)`: delegate to repo

    - `RecordSickLeave(ctx, tenantID, employeeID uuid.UUID, input SickLeaveInput) (*models.LeaveRequest, error)`:
      - Find "krank" leave type for tenant
      - Calculate duration, check AU threshold
      - Create leave request with status "approved" (sick leave doesn't require approval)
      - If duration >= au_threshold: set au_document_required = true, emit "hr.sick.au_required" event
      - Return the created request

    Create `service_test.go` with unit tests using mock repositories:
    - Test CreateLeaveRequest creates with pending status and correct total_days for half-day requests
    - Test ApproveLeaveRequest transitions status and updates balance
    - Test ApproveLeaveRequest with overlapping requests returns overlap info but succeeds
    - Test RejectLeaveRequest transitions status
    - Test CancelLeaveRequest restores balance for approved requests
    - Test sick leave auto-approves and flags AU when over threshold
    - Test approval by non-manager returns ErrNotAuthorizedToApprove

    **Employee Service Package (`backend/internal/biz/hr/employee/`)**

    Create `errors.go` with domain errors:
    - ErrEmployeeNotFound, ErrProfileAlreadyExists, ErrUnauthorizedFieldUpdate, ErrDocumentCategoryNotFound, ErrDocumentNotFound, ErrInsufficientDocumentAccess

    Create `repository.go` with interfaces:

    ```go
    type EmployeeRepository interface {
        Create(ctx context.Context, profile *models.EmployeeProfile) error
        GetByID(ctx context.Context, id uuid.UUID) (*models.EmployeeProfile, error)
        GetByUserID(ctx context.Context, userID uuid.UUID) (*models.EmployeeProfile, error)
        List(ctx context.Context, filter EmployeeFilter) ([]*models.EmployeeProfile, int, error)
        Update(ctx context.Context, profile *models.EmployeeProfile) error
    }

    type DocumentCategoryRepository interface {
        ListByTenant(ctx context.Context, tenantID uuid.UUID) ([]*models.HRDocumentCategory, error)
        GetByID(ctx context.Context, id uuid.UUID) (*models.HRDocumentCategory, error)
    }

    type EmployeeDocumentRepository interface {
        Create(ctx context.Context, doc *models.EmployeeDocument) error
        ListByEmployee(ctx context.Context, employeeID uuid.UUID, callerRole string) ([]*models.EmployeeDocument, error)
        Delete(ctx context.Context, id uuid.UUID) error
    }
    ```

    `EmployeeFilter`: TenantID, Department (optional), ManagerUserID (optional), Page, PerPage.

    Create `postgres_repository.go` implementing all three interfaces:
    - EmployeeRepository: standard CRUD with pgx. List joins with users table to get name/email for display.
    - DocumentCategoryRepository: simple SELECT with tenant_id filter, ORDER BY sort_order.
    - EmployeeDocumentRepository:
      - ListByEmployee filters by visibility based on callerRole:
        - "admin" or "hr": see all categories
        - "manager": see categories with visibility IN ('manager', 'employee')
        - "employee" (self): see categories with visibility = 'employee'
      - JOIN with hr_document_categories to filter by visibility

    Create `service.go` with `Service` struct:
    ```go
    type Service struct {
        employeeRepo  EmployeeRepository
        docCatRepo    DocumentCategoryRepository
        docRepo       EmployeeDocumentRepository
    }
    ```

    Service methods:

    - `ListEmployees(ctx, filter EmployeeFilter) ([]*models.EmployeeProfile, int, error)`: delegate to repo with pagination
    - `GetEmployee(ctx, id uuid.UUID) (*models.EmployeeProfile, error)`: delegate to repo
    - `GetByUserID(ctx, userID uuid.UUID) (*models.EmployeeProfile, error)`: delegate to repo

    - `UpdateEmployee(ctx, id uuid.UUID, input UpdateEmployeeInput, callerRole string) (*models.EmployeeProfile, error)`:
      - Per locked decision: limited self-service
      - If callerRole is "employee": only allow updating emergency_contact_name, emergency_contact_phone, address_street, address_city, address_postal_code, address_country
      - If callerRole is "admin", "hr", or "manager": allow updating department, position_title, contract_type, work_days_per_week, annual_leave_days, manager_user_id, start_date + all self-service fields
      - Return ErrUnauthorizedFieldUpdate if employee tries to change restricted fields

    - `UpdateSelfProfile(ctx, userID uuid.UUID, input SelfProfileInput) (*models.EmployeeProfile, error)`:
      - Convenience method: looks up profile by userID, calls UpdateEmployee with role="employee"
      - SelfProfileInput: EmergencyContactName, EmergencyContactPhone, AddressStreet, AddressCity, AddressPostalCode, AddressCountry

    - `ListEmployeeDocuments(ctx, employeeID uuid.UUID, callerUserID uuid.UUID, callerRole string) ([]*models.EmployeeDocument, error)`:
      - Pass callerRole to repo for visibility filtering

    - `UploadEmployeeDocument(ctx, tenantID uuid.UUID, input UploadDocumentInput) (*models.EmployeeDocument, error)`:
      - Validate category exists
      - Create EmployeeDocument record linking to the file_id from Phase 11 document service
      - The actual file upload happens via the existing document service /api/v1/files/upload endpoint; this just creates the HR link
      - Return the created document record

    - `ListDocumentCategories(ctx, tenantID uuid.UUID) ([]*models.HRDocumentCategory, error)`: delegate to repo

    **HRSettingsRepository** -- implement in a shared location since both leave and employee services need it:
    Create as part of leave package (leave.HRSettingsRepository) since it was defined there, but the postgres implementation in `leave/postgres_repository.go` can be used by both.
