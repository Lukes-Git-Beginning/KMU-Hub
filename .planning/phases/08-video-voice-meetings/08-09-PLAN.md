    **PresenceIndicator.tsx:**
    Small colored dot indicating user's presence status.
    Props: userId: string, size?: 'sm' | 'md' | 'lg', className?: string.

    - Reads presence from usePresenceStore
    - Renders a colored dot:
      - online: green (#22c55e), solid
      - away: yellow (#eab308), solid
      - offline: gray (#9ca3af), ring/outline only
      - in_call: red (#ef4444), pulsing animation
    - Size variants: sm (w-2 h-2), md (w-3 h-3), lg (w-3.5 h-3.5)
    - Position: designed to overlay bottom-right of avatar (absolute positioning relative to parent)
    - Tooltip on hover showing status text: "Online", "Abwesend", "Offline", "Im Gespraech"

    **PresenceProvider.tsx:**
    App-level provider that manages presence heartbeats and WebSocket presence updates.
    Must be mounted near the app root (inside AppShell or as a wrapper).

    Functionality:
    1. **Heartbeat**: Send `presence.heartbeat` via WebSocket every 30 seconds
       - Use setInterval (30s) starting when component mounts
       - Clear on unmount
       - Only send when user is authenticated (check auth store)

    2. **Activity detection**: Track user activity (mouse move, keypress, focus)
       - If no activity for 5 minutes, stop sending heartbeats (user will naturally transition to "away" on server side)
       - Resume heartbeats on activity detection
       - Use throttled event listeners (check activity every 60s, not every event)

    3. **WebSocket listener**: Listen for `presence.update` messages
       - On receive: updatePresence(userId, status) in presence store
       - Also listen for `call.started`, `call.ended` to update in_call status for other users

    4. **Bulk presence loading**: On mount and periodically (every 30s), fetch presence for visible/known users
       - Collect user IDs from visible channels, DMs, sidebar
       - Call useBulkPresence hook to fetch statuses
       - Update presence store with results

    Render: children only (transparent provider, no visible UI).

    **usePresenceTracking.ts:**
    Custom hook encapsulating the heartbeat and activity detection logic.
    Returns: { isActive: boolean, isTracking: boolean }
    - Used internally by PresenceProvider
    - Exported for potential reuse

    **index.ts:**
    Barrel exports for PresenceIndicator, PresenceProvider, usePresenceTracking.
