  <action>
    Follow the exact patterns from existing hooks (useMessages.ts, useChannels.ts, useTasks.ts).

    **useCalls.ts:**
    - `useCreateCall()` -- mutation: POST /calls, returns JoinCallResponse
    - `useJoinCall()` -- mutation: POST /calls/{callId}/join, returns JoinCallResponse
    - `useLeaveCall()` -- mutation: POST /calls/{callId}/leave
    - `useEndCall()` -- mutation: POST /calls/{callId}/end
    - `useStartCallFromChat()` -- mutation: POST /calls/from-chat/{channelId}, returns JoinCallResponse
    - `useActiveCalls()` -- query: GET /calls/active, returns Call[]
    - `useCallHistory(offset, limit)` -- query: GET /calls/history, returns { calls: Call[], total: number }
    - `useCall(callId)` -- query: GET /calls/{callId}, returns Call with participants
    - `useLiveKitURL()` -- query: GET /calls/livekit-url, returns { ws_url: string }, staleTime: Infinity (URL doesn't change)

    **useMeetings.ts:**
    - `useCreateMeeting()` -- mutation: POST /meetings
    - `useUpdateMeeting()` -- mutation: PUT /meetings/{meetingId}
    - `useDeleteMeeting()` -- mutation: DELETE /meetings/{meetingId}
    - `useRSVPMeeting()` -- mutation: POST /meetings/{meetingId}/rsvp
    - `useStartMeeting()` -- mutation: POST /meetings/{meetingId}/start, returns { meeting, token }
    - `useEndMeeting()` -- mutation: POST /meetings/{meetingId}/end
    - `useMeetings(filters)` -- query: GET /meetings with query params
    - `useMeeting(meetingId)` -- query: GET /meetings/{meetingId}
    - `useCreateNote()` -- mutation: POST /meetings/{meetingId}/notes
    - `useUpdateNote()` -- mutation: PUT /meetings/notes/{noteId}
    - `useMeetingNotes(meetingId)` -- query: GET /meetings/{meetingId}/notes
    - `useCreateActionItem()` -- mutation: POST /meetings/{meetingId}/action-items
    - `useUpdateActionItem()` -- mutation: PUT /meetings/action-items/{itemId}
    - `useCompleteActionItem()` -- mutation: POST /meetings/action-items/{itemId}/complete
    - `useMeetingActionItems(meetingId)` -- query: GET /meetings/{meetingId}/action-items

    **useRecordings.ts:**
    - `useRequestRecording()` -- mutation: POST /calls/{callId}/recordings
    - `useStopRecording()` -- mutation: DELETE /calls/{callId}/recordings/active
    - `useSubmitConsent()` -- mutation: POST /calls/{callId}/recordings/consent
    - `useRecordings(callId)` -- query: GET /calls/{callId}/recordings
    - `useRecording(recordingId)` -- query: GET /recordings/{recordingId}

    **useReactions.ts:**
    - `useToggleReaction()` -- mutation: POST /messages/{messageId}/reactions, body: { emoji }
      On success, invalidate the message reactions query for that messageId.
      Also update the reactions in message list cache via optimistic update if possible.
    - `useMessageReactions(messageId)` -- query: GET /messages/{messageId}/reactions, returns ReactionSummary[]

    **usePresence.ts:**
    - `useBulkPresence(userIds)` -- query: POST /presence/bulk, returns map of userId -> PresenceStatus
      Configure: refetchInterval: 30000 (refresh every 30s), staleTime: 15000 (15s stale time)
      Only fetch if userIds.length > 0.

    **Zustand stores:**

    **stores/call.ts:**
    ```typescript
    interface CallState {
      // Active call
      activeCall: Call | null;
      token: string | null;
      wsUrl: string | null;
      isMinimized: boolean;

      // Incoming call
      incomingCall: { callId: string; initiatedBy: string; channelId?: string } | null;

      // Recording
      isRecording: boolean;
      consentPending: boolean;

      // Actions
      setActiveCall: (call: Call, token: string, wsUrl: string) => void;
      clearActiveCall: () => void;
      setMinimized: (minimized: boolean) => void;
      setIncomingCall: (data: { callId: string; initiatedBy: string; channelId?: string } | null) => void;
      setRecording: (recording: boolean) => void;
      setConsentPending: (pending: boolean) => void;
    }
    ```

    **stores/presence.ts:**
    ```typescript
    interface PresenceState {
      // Cache: userId -> { status, lastUpdated }
      presenceCache: Map<string, { status: PresenceStatus; lastUpdated: number }>;

      // Actions
      updatePresence: (userId: string, status: PresenceStatus) => void;
      updateBulkPresence: (statuses: Record<string, PresenceStatus>) => void;
      getPresence: (userId: string) => PresenceStatus;
      clearStale: (maxAgeMs: number) => void;
    }
    ```
    Use Map for O(1) lookups. Default unknown users to 'offline'. clearStale removes entries older than maxAgeMs to prevent memory growth.

    Both stores: use `create` from zustand with no middleware (same pattern as existing stores).
