    **errors.go:**

    **service.go:**
    Create `Service` struct with `*redis.Client` dependency.

    Constants (from research):
    ```go
    const (
        presenceKey     = "presence:heartbeats"
        presenceTimeout = 60 * time.Second   // Offline after 60s without heartbeat
        awayTimeout     = 300 * time.Second  // Away after 5 min idle
    )
    ```

    Methods:
    - `Heartbeat(ctx, userID string) error`:
      ZADD presence:heartbeats with score=current Unix timestamp, member=userID.
      This is called every 30 seconds from the frontend via WebSocket.

    - `SetInCall(ctx, userID string, inCall bool) error`:
      If inCall: SET presence:incall:{userID} "1" with 4h TTL.
      If !inCall: DEL presence:incall:{userID}.
      Called by room service when user joins/leaves a call.

    - `GetStatus(ctx, userID string) (models.PresenceStatus, error)`:
      1. Check incall key
      2. If incall -> return StatusInCall
      3. ZSCORE to get last heartbeat timestamp
      4. If not found -> return StatusOffline
      5. Calculate elapsed time since last heartbeat
      6. If elapsed > presenceTimeout -> StatusOffline
      7. If elapsed > awayTimeout -> StatusAway
      8. Otherwise -> StatusOnline

    - `GetBulkStatus(ctx, userIDs []string) (map[string]models.PresenceStatus, error)`:
      Use Redis PIPELINE for efficiency (research Pattern 3):
      1. Pipeline ZSCORE for each userID + EXISTS for each incall key
      2. Execute pipeline in single round-trip
      3. Apply same logic as GetStatus for each user
      4. Return map of userID -> status

    - `SetAway(ctx, userID string) error`:
      Set the heartbeat score to (now - awayTimeout) so the user appears away without waiting for natural timeout. Called when user explicitly sets away status.

    - `CleanupStale(ctx) (int, error)`:
      ZREMRANGEBYSCORE to remove entries older than 24 hours. This is a maintenance method that can be called periodically (e.g., every hour). Returns count of removed entries.

    - `GetOnlineUsers(ctx) ([]string, error)`:
      ZRANGEBYSCORE with min=(now - presenceTimeout) to get all currently online users. Useful for presence indicators across the app.

    All methods should handle Redis errors gracefully: log the error and return ErrPresenceUnavailable. Callers should treat presence as best-effort (graceful degradation -- if Redis is down, show all users as offline rather than crashing).
