    **postgres_repository.go:**
    Implement all methods with pgxpool. Key details:
    - `ListCallHistory` joins with `call_participants` to filter calls the user participated in. Returns total count for pagination.
    - `GetActiveParticipantCount` counts participants WHERE left_at IS NULL.
    - `AddParticipant` uses the UNIQUE constraint (call_id, user_id, joined_at) to prevent duplicates.

    **service.go:**
    Create `Service` struct with dependencies:
    - `roomClient *lksdk.RoomServiceClient` -- LiveKit room operations
    - `apiKey, apiSecret string` -- for token generation
    - `wsURL string` -- LiveKit WebSocket URL (returned to clients for connection)
    - `repo Repository` -- call persistence
    - `eventEmitter EventEmitter` -- for pg_notify events (interface: `EmitEvent(ctx, eventType string, payload map[string]interface{}) error`)

    Constructor: `NewService(livekitHost, apiKey, apiSecret string, repo Repository, emitter EventEmitter) *Service`
    Initialize `roomClient` via `lksdk.NewRoomServiceClient(livekitHost, apiKey, apiSecret)`.

    Methods:
    - `CreateCall(ctx, initiatorID uuid.UUID, callType models.CallType, channelID *uuid.UUID, maxParticipants int) (*models.Call, string, error)`:
      1. Generate room name: `call-{initiatorID[:8]}-{timestamp}` (research pattern)
      2. Create LiveKit room via `roomClient.CreateRoom` with EmptyTimeout=300 (5 min)
      3. Persist Call record in PostgreSQL with status=active
      4. Generate join token for initiator via `GenerateJoinToken`
      5. Emit "call.started" event via pg_notify
      6. Return (call, token, nil)

    - `GenerateJoinToken(roomName, userID, userName string) (string, error)`:
      Use `auth.NewAccessToken(apiKey, apiSecret)` with VideoGrant{RoomJoin: true, Room: roomName}. Set identity=userID, name=userName, valid for 4 hours. Return JWT.

    - `JoinCall(ctx, callID, userID uuid.UUID, userName string) (token string, wsURL string, err error)`:
      1. Get call, verify status=active
      2. Add participant record
      3. Generate join token
      4. Return (token, s.wsURL, nil)

    - `LeaveCall(ctx, callID, userID uuid.UUID) error`:
      1. Get participant, set left_at=now
      2. Check active participant count; if 0, call EndCall

    - `EndCall(ctx, callID uuid.UUID) error`:
      1. Get call, verify not already ended
      2. Set status=ended, ended_at=now, calculate duration_seconds
      3. Mark all participants with left_at if still NULL
      4. Delete LiveKit room via `roomClient.DeleteRoom` (best effort, room may already be gone)
      5. Emit "call.ended" event

    - `GetCall(ctx, callID uuid.UUID) (*models.Call, []models.CallParticipant, error)`:
      Return call with its participants.

    - `ListActiveCalls(ctx) ([]models.Call, error)`:
      Return all active calls.

    - `GetCallHistory(ctx, userID uuid.UUID, offset, limit int) ([]models.Call, int, error)`:
      Return paginated call history for user.

    - `StartCallFromChat(ctx, initiatorID uuid.UUID, channelID uuid.UUID) (*models.Call, string, error)`:
      Convenience wrapper that calls `CreateCall` with callType based on channel type (DM -> direct, channel -> channel) and channelID set.

    - `GetLiveKitWSURL() string`: Return the WebSocket URL for frontend LiveKit connection.

    Create `backend/internal/video/recording/` package.

    **errors.go:**
    - `ErrRecordingNotFound` -- recording does not exist
    - `ErrRecordingAlreadyActive` -- call already has an active recording
    - `ErrConsentPending` -- not all participants have responded to consent request
    - `ErrConsentDenied` -- at least one participant denied recording consent
    - `ErrNoActiveRecording` -- attempting to stop but no recording active
    - `ErrCallNotActive` -- call must be active to start recording

    **repository.go:**
    ```go
    type Repository interface {
        CreateRecording(ctx context.Context, rec *models.CallRecording) error
        GetRecording(ctx context.Context, id uuid.UUID) (*models.CallRecording, error)
        GetActiveRecording(ctx context.Context, callID uuid.UUID) (*models.CallRecording, error)
        UpdateRecording(ctx context.Context, rec *models.CallRecording) error
        ListRecordingsByCall(ctx context.Context, callID uuid.UUID) ([]models.CallRecording, error)

        CreateConsent(ctx context.Context, consent *models.RecordingConsent) error
        GetConsent(ctx context.Context, callID, userID uuid.UUID) (*models.RecordingConsent, error)
        ListConsentsByCall(ctx context.Context, callID uuid.UUID) ([]models.RecordingConsent, error)
        AllParticipantsConsented(ctx context.Context, callID uuid.UUID) (allResponded bool, allConsented bool, err error)
    }
    ```

    **postgres_repository.go:**
    - `GetActiveRecording`: SELECT WHERE call_id AND status='recording' LIMIT 1
    - `AllParticipantsConsented`: Compare count of consents with count of active participants in call. Return (allResponded, allConsented) -- allResponded=true when consent count >= active participant count, allConsented=true when all consented=true.
    - `CreateConsent`: INSERT with ON CONFLICT (call_id, user_id) DO UPDATE SET consented=EXCLUDED.consented, responded_at=EXCLUDED.responded_at (allow changing consent).

    **service.go:**
    Create `Service` struct with dependencies:
    - `egressClient EgressClient` -- interface wrapping LiveKit EgressClient for testability
    - `repo Repository`
    - `roomRepo room.Repository` -- to check active participant count (or pass via parameter)
    - `minioCfg MinIOConfig` -- from research pattern
    - `eventEmitter EventEmitter`

    Define `EgressClient` interface:
    ```go
    type EgressClient interface {
        StartRoomCompositeEgress(ctx context.Context, req *livekit.RoomCompositeEgressRequest) (*livekit.EgressInfo, error)
        StopEgress(ctx context.Context, req *livekit.StopEgressRequest) (*livekit.EgressInfo, error)
    }
    ```

    Define `MinIOConfig` struct: Endpoint, AccessKey, SecretKey, Bucket (from research).

    Methods:
    - `RequestRecording(ctx, callID uuid.UUID, requestedBy uuid.UUID) error`:
      1. Verify no active recording for this call (ErrRecordingAlreadyActive)
      2. Create recording record with status="pending_consent"
      3. Emit "call.recording.consent_required" event via pg_notify (this triggers WebSocket notification to all participants)
      This does NOT start recording yet. It initiates the consent flow.

    - `SubmitConsent(ctx, callID, userID uuid.UUID, consented bool) error`:
      1. Store consent record (CreateConsent -- upsert)
      2. Check `AllParticipantsConsented`:
         - If not all responded yet -> do nothing (wait)
         - If all responded AND all consented -> call `startEgress` internally
         - If all responded AND any denied -> mark recording as "cancelled", emit "call.recording.denied" event
      3. Emit "call.recording.consent_update" event with current consent state

    - `startEgress(ctx, callID uuid.UUID, roomName string) error` (private):
      1. Build `RoomCompositeEgressRequest` with grid layout, MP4 output to MinIO (S3Upload with ForcePathStyle=true)
      2. File path: `recordings/{callID}/{date}.mp4`
      3. Call `egressClient.StartRoomCompositeEgress`
      4. Update recording record: status="recording", egress_id from response
      5. Emit "call.recording.started" event

    - `StopRecording(ctx, callID uuid.UUID) error`:
      1. Get active recording for call (ErrNoActiveRecording if none)
      2. Call `egressClient.StopEgress` with egress_id
      3. Update recording: status="completed", completed_at=now
      4. Emit "call.recording.stopped" event

    - `GetRecording(ctx, recordingID uuid.UUID) (*models.CallRecording, error)`:
      Return recording metadata.

    - `ListRecordings(ctx, callID uuid.UUID) ([]models.CallRecording, error)`:
      Return all recordings for a call.

    - `GetConsentStatus(ctx, callID uuid.UUID) ([]models.RecordingConsent, bool, bool, error)`:
      Return all consents + allResponded + allConsented flags.

    - `TestStartEgress_MinIOConfig`: Verify S3Upload has ForcePathStyle=true, correct bucket/endpoint
