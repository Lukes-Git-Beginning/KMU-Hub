    ```go
    type Repository interface {
        CreateCallSession(ctx context.Context, session *CallSession) error
        GetCallSession(ctx context.Context, id uuid.UUID) (*CallSession, error)
        GetCallSessionByRoomName(ctx context.Context, roomName string) (*CallSession, error)
        UpdateCallSession(ctx context.Context, session *CallSession) error
        ListActiveCallsForUser(ctx context.Context, userID uuid.UUID) ([]CallSession, error)
        AddParticipant(ctx context.Context, p *CallParticipant) error
        RemoveParticipant(ctx context.Context, callID, userID uuid.UUID) error
        GetParticipants(ctx context.Context, callID uuid.UUID) ([]CallParticipant, error)
        CountActiveParticipants(ctx context.Context, callID uuid.UUID) (int, error)
    }
    ```

    **PostgreSQL repository** (`postgres_repository.go`):
    - Implement all methods using pgx.Pool
    - ListActiveCallsForUser: JOIN call_participants ON call_id WHERE user_id=$1 AND call_sessions.status != 'ended' AND call_participants.left_at IS NULL
    - RemoveParticipant: UPDATE call_participants SET left_at=NOW() WHERE call_id=$1 AND user_id=$2 AND left_at IS NULL
    - CountActiveParticipants: COUNT WHERE left_at IS NULL

    **Service** (`service.go`):
    ```go
    type Service struct {
        repo       Repository
        roomClient *lksdk.RoomServiceClient  // nil if LiveKit disabled
        apiKey     string
        apiSecret  string
        wsURL      string
        enabled    bool
    }
    ```

    Constructor: `NewService(repo Repository, apiKey, apiSecret, wsURL string)`. If any LiveKit config is empty, set enabled=false and roomClient=nil.

    Methods:
    - `CreateCall(ctx, initiatorID uuid.UUID, callType CallType, targetUserIDs []uuid.UUID, channelID *uuid.UUID) (*CallSession, string, error)`:
      1. If !enabled, return ErrLiveKitNotConfigured
      2. Generate room name: "call-" + uuid.New().String()[:8]
      3. Create LiveKit room via roomClient.CreateRoom with MaxParticipants (2 for 1:1, 25 for group)
      4. EmptyTimeout: 10 minutes
      5. Insert CallSession with status=ringing
      6. Add initiator as first participant
      7. Generate join token for initiator using lkauth.NewAccessToken (same pattern as existing livekit/service.go)
      8. Return session, token, nil

    - `JoinCall(ctx, callID, userID uuid.UUID, displayName string) (string, error)`:
      1. Get call session, verify status != ended
      2. Check max participants (25 for group)
      3. Add participant
      4. If status is ringing, update to active
      5. Generate and return join token

    - `EndCall(ctx, callID, userID uuid.UUID) error`:
      1. Get session, verify exists
      2. Update status to ended, set ended_at and duration_seconds
      3. Delete LiveKit room via roomClient.DeleteRoom (if enabled)
      4. Mark all active participants as left

    - `GetCall(ctx, callID uuid.UUID) (*CallSession, error)`: Get session with participants.

    - `ListActiveCalls(ctx, userID uuid.UUID) ([]CallSession, error)`: Delegate to repo.

    - `HandleParticipantJoined(ctx, roomName, userIdentity string) error`:
      For LiveKit webhook -- find session by room name, add/update participant.

    - `HandleParticipantLeft(ctx, roomName, userIdentity string) error`:
      For LiveKit webhook -- mark participant left. If no active participants remain, end call.

    - `HandleRoomFinished(ctx, roomName string) error`:
      For LiveKit webhook -- end call session if still active.

    ```go
        CreateRecording(ctx context.Context, rec *Recording) error
        GetRecording(ctx context.Context, id uuid.UUID) (*Recording, error)
        UpdateRecording(ctx context.Context, rec *Recording) error
        ListRecordingsByCall(ctx context.Context, callID uuid.UUID) ([]Recording, error)

        DeleteRecording(ctx context.Context, id uuid.UUID) error
        SetConsent(ctx context.Context, consent *RecordingConsent) error

        CountPendingConsents(ctx context.Context, recordingID uuid.UUID, participantIDs []uuid.UUID) (int, error)

    }
    ```

    **PostgreSQL repository** (`postgres_repository.go`):
    - SetConsent: INSERT ON CONFLICT (recording_id, user_id) DO UPDATE SET consented=$3, responded_at=NOW()
    - CountPendingConsents: Count participants in participantIDs who have NOT responded (LEFT JOIN recording_consents WHERE consented IS NULL)
    - ListExpiredRecordings: WHERE retention_expires_at < $1 AND status = 'completed'

    **Service** (`service.go`):
    ```go
    type EgressManager interface {
        StartRoomCompositeEgress(ctx context.Context, roomName, templateURL string, s3Config S3Config) (string, error)  // returns egressID
        StopEgress(ctx context.Context, egressID string) error
    }

    type S3Config struct {
        Endpoint, AccessKey, Secret, Bucket string
    }

    type Service struct {
        repo           Repository
        egressManager  EgressManager  // nil if not configured
        minioEndpoint  string
        minioAccessKey string
        minioSecret    string
        minioBucket    string
        templateURL    string
        enabled        bool
    }
    ```

    Methods:
    - `StartRecording(ctx, callID *uuid.UUID, meetingID *uuid.UUID, participantIDs []uuid.UUID) (*Recording, error)`:
      1. Create Recording with status=active
      2. Set retention_expires_at = NOW() + 30 days (per user decision)
      3. For each participant, check if consent exists. If any participant has NOT responded, return ErrConsentPending
      4. If any participant declined, recording proceeds but those participants will be blurred/muted (handled by egress template via metadata)
      5. Start Egress via egressManager with custom template URL and S3 config pointing to MinIO
      6. Store egress_id on recording
      7. Return recording

    - `StopRecording(ctx, recordingID uuid.UUID) (*Recording, error)`:
      1. Get recording, verify status=active
      2. Stop Egress via egressManager
      3. Update status to processing (Egress takes time to finalize)

    - `SetConsent(ctx, recordingID, userID uuid.UUID, consented bool) error`:
      1. Validate recording exists and is in active/pending state
      2. Store consent via repo
      3. Return nil

    - `GetConsentStatus(ctx, recordingID uuid.UUID, participantIDs []uuid.UUID) (allResponded bool, consents []RecordingConsent, error)`:
      1. Get all consents for recording
      2. Check if all participantIDs have responded
      3. Return status

    - `CompleteRecording(ctx, recordingID uuid.UUID, fileURL string, fileSizeBytes int64, durationSeconds int) error`:
      For webhook callback when Egress finishes -- update recording with file info, set status=completed.

    - `FailRecording(ctx, recordingID uuid.UUID, reason string) error`:
      For webhook callback when Egress fails -- set status=failed.

    - `CleanupExpiredRecordings(ctx context.Context) (int, error)`:
      1. List expired recordings via repo.ListExpiredRecordings(time.Now())
      2. For each: delete from MinIO (via S3 API), set status=deleted
      3. Return count of cleaned up recordings
      Note: This will be called by a periodic goroutine or cron (wired in 08-05)

    - `ListRecordings(ctx, callID *uuid.UUID, meetingID *uuid.UUID) ([]Recording, error)`: Delegate based on which ID is provided.
