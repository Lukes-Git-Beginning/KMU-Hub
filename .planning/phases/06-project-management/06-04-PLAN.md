NOTE: This task implements 3 integration layers (gRPC server with ~35 RPCs, gateway with ~30 HTTP routes, service entry point) as one cohesive wiring task. These are tightly coupled: the gRPC server defines the methods, the gateway routes map to them 1:1, and the entry point initializes both. Splitting would create artificial boundaries between layers that must stay in sync. Each layer is mechanical (converter + delegation code), not complex business logic.

**backend/internal/server/work_grpc.go:**
Create gRPC server implementing `workv1.WorkServiceServer` (generated from proto).

Constructor takes all services: project.Service, status.Service, task.Service, comment.Service.

Implement all RPC methods by:
1. Extracting user_id and is_admin from gRPC metadata (follow pattern from crm_grpc.go)
2. Converting proto request to service input struct
3. Calling appropriate service method
4. Converting service response to proto response
5. Mapping service errors to gRPC status codes (NotFound -> codes.NotFound, validation errors -> codes.InvalidArgument, permission errors -> codes.PermissionDenied)

Key converter functions:
- `taskToProto(*models.TaskWithRelations) *workv1.TaskProto` -- formats task_number with project_key as "ACME-42"
- `projectToProto(*models.Project) *workv1.ProjectProto`
- `commentToProto(*models.TaskCommentWithAuthor) *workv1.TaskCommentProto`
- `activityToProto(*models.TaskActivity) *workv1.TaskActivityProto`

For timestamps: use `timestamppb.New(t)` for conversion (same pattern as crm_grpc.go).

**backend/internal/gateway/route_work.go:**
Follow `route_crm.go` pattern exactly:

```go
type WorkRoutes struct {
    registry *ServiceRegistry
}

func NewWorkRoutes(registry *ServiceRegistry) *WorkRoutes {
    return &WorkRoutes{registry: registry}
}

func (w *WorkRoutes) ServiceName() string { return "work" }

func (w *WorkRoutes) getWorkClient() (workv1.WorkServiceClient, error) {
    conn, err := w.registry.GetConnection("work")
    if err != nil {
        return nil, err
    }
    return workv1.NewWorkServiceClient(conn), nil
}
```
