Create `gantt-utils.ts` with all date math, positioning, and critical path logic for the Gantt chart. This is pure logic with no React -- can be unit tested independently.

**Types:**

```typescript
export interface GanttTask {
  id: string
  title: string
  project_key?: string
  task_number: number
  start: Date | null   // derived: earliest of created_at or dependency-implied start
  end: Date | null     // from due_date
  priority: string
  status_name?: string
  status_color?: string
  assignee_name?: string
  parent_task_id?: string | null
  depth: number
  completed_at?: string | null
  is_on_critical_path: boolean
}

export interface GanttDependency {
  id: string
  source_task_id: string
  target_task_id: string
  dependency_type: string  // only render arrows for 'blocks' and 'blocked_by'
}

export type ZoomLevel = 'day' | 'week' | 'month'

export interface TimelineConfig {
  startDate: Date       // left edge of visible timeline
  endDate: Date         // right edge of visible timeline
  zoom: ZoomLevel
  columnWidth: number   // pixels per unit (day/week/month)
}
```

**Constants:**

```typescript
export const COLUMN_WIDTHS: Record<ZoomLevel, number> = {
  day: 40,    // 40px per day
  week: 120,  // 120px per week (~17px/day)
  month: 200, // 200px per month (~6.7px/day)
}

export const ROW_HEIGHT = 36  // px per task row
export const BAR_HEIGHT = 20  // px for the task bar within the row
export const HEADER_HEIGHT = 48  // timeline header
```

**Functions:**

1. `buildTimelineConfig(tasks: GanttTask[], zoom: ZoomLevel): TimelineConfig`
   - Scans all tasks to find the earliest start and latest end
   - Adds 2 weeks of padding on each side
   - If no tasks have dates, defaults to current month +/- 1 month
   - Returns startDate, endDate, zoom, and columnWidth from COLUMN_WIDTHS

2. `dateToX(date: Date, config: TimelineConfig): number`
   - Converts a date to an X pixel position relative to the timeline start
   - Uses `differenceInCalendarDays` from date-fns for day-level precision
   - Formula: `daysDiff * (columnWidth / daysPerUnit)` where daysPerUnit is 1 (day), 7 (week), ~30 (month)

3. `xToDate(x: number, config: TimelineConfig): Date`
   - Inverse of dateToX -- converts pixel X back to a Date

4. `generateTimelineColumns(config: TimelineConfig): { date: Date; label: string; isWeekend: boolean; isToday: boolean }[]`
   - Generates column data for the timeline header
   - For day zoom: each column is one day, label = "Mo 3.", "Di 4." etc. (German short day + date)
   - For week zoom: each column is one week, label = "KW 6" (Kalenderwoche)
   - For month zoom: each column is one month, label = "Feb 2026"
   - Uses date-fns `eachDayOfInterval`, `eachWeekOfInterval`, `eachMonthOfInterval`
   - Marks weekends and today for visual highlighting

5. `taskToBar(task: GanttTask, config: TimelineConfig): { x: number; width: number; y: number } | null`
   - Returns null if task has no start AND no end (unscheduled)
   - If task has end but no start: use end - 1 day as start (minimum bar width)
   - If task has start but no end: use start + 3 days as default duration
   - x = dateToX(start, config), width = dateToX(end, config) - x, minimum 12px
   - y is not set here (determined by row index in the chart)

6. `calculateCriticalPath(tasks: GanttTask[], dependencies: GanttDependency[]): Set<string>`
   - Forward pass: for each task, compute earliest start (ES) and earliest finish (EF)
     - ES = max(EF of all predecessors in 'blocks' deps, task's own start)
     - EF = ES + duration
   - Backward pass: for each task from latest to earliest, compute latest finish (LF) and latest start (LS)
     - LF = min(LS of all successors, project end)
     - LS = LF - duration
   - Critical tasks: where ES === LS (no slack/float)
   - Returns Set of task IDs on the critical path
   - Only considers 'blocks' and 'blocked_by' dependency types (not relates_to/duplicates)

7. `separateScheduledAndUnscheduled(tasks: GanttTask[]): { scheduled: GanttTask[]; unscheduled: GanttTask[] }`
   - Scheduled: has due_date (end is not null)
   - Unscheduled: no due_date

8. `mapApiTasksToGantt(apiTasks: any[], dependencies: any[]): { tasks: GanttTask[]; dependencies: GanttDependency[] }`
   - Converts API response tasks to GanttTask objects
   - Maps due_date string to Date, created_at to start (fallback)
   - Initializes is_on_critical_path to false (calculated separately)
   - Filters dependencies to only blocks/blocked_by types for arrow rendering

All date operations use `date-fns` (already installed). Use `startOfDay`, `endOfDay`, `differenceInCalendarDays`, `addDays`, `format` with German locale (`de`). Import locale: `import { de } from 'date-fns/locale'`.
