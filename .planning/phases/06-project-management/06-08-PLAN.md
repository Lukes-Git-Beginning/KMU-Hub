**TaskLinkField.tsx:**
Search-and-link component for CRM entity linking (per locked decision: context-aware auto-suggest).

Props: `taskId: string`, `existingLinks: TaskEntityLink[]`

Structure:
- "Verknuepfung hinzufuegen" button opens a search popover
- Search input with entity type tabs/filter: Alle, Kontakte, Unternehmen, Deals, Channels, Nachrichten
- As user types, search across entities using the existing CRM search API (`/api/v1/search?q=...&type=contact,company,deal`). For chat entities, use `/api/v1/channels?search=...` and `/api/v1/messages/search?q=...`.
- Results shown in dropdown: icon per type + entity name + subtitle (e.g., company name for contacts, pipeline stage for deals, channel name for messages)
- Clicking a result calls POST /api/v1/tasks/{taskId}/links with { entity_type, entity_id }
- Context-aware auto-suggest: When task title or description contains text matching a CRM entity name (e.g., "Acme" matches company "Acme Corp"), show suggestions automatically in a subtle banner above the link field: "Meinten Sie: Acme Corp (Unternehmen)?" User clicks to confirm link. Suggestions never auto-applied (per locked decision).

Existing links displayed as chips:
- Icon per type + entity display name
- Clickable: navigates to the entity (contact detail, deal detail, chat channel)
- X button to remove link (calls DELETE /api/v1/tasks/{id}/links/{linkId})

**Extend useTasks.ts:**
Add hooks for entity links:
```typescript
export function useTaskEntityLinks(taskId: string) -- GET /api/v1/tasks/{id}/links
export function useLinkEntity() -- POST /api/v1/tasks/{id}/links
export function useUnlinkEntity() -- DELETE /api/v1/tasks/{id}/links/{linkId}
export function useEntityTasks(entityType: string, entityId: string) -- GET /api/v1/entities/{type}/{id}/tasks
```
