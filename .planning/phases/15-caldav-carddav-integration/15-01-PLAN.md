    - `id UUID PRIMARY KEY DEFAULT uuid_generate_v4()`
    - `user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE`
    - `label VARCHAR(100) NOT NULL` -- user-chosen name, e.g. "Thunderbird Buero"

    - `last_used_at TIMESTAMPTZ` -- updated on successful auth
    - `created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()`
    - `revoked_at TIMESTAMPTZ` -- NULL = active, set = revoked

    Indexes:
    - `idx_app_passwords_user ON app_specific_passwords (user_id)`
    - `idx_app_passwords_active ON app_specific_passwords (user_id) WHERE revoked_at IS NULL`

    **Repository interface** in `backend/internal/caldav/app_password_repo.go`:
    ```go
    type AppPasswordRepository interface {
        Create(ctx context.Context, pw *models.AppSpecificPassword) error
        ListByUser(ctx context.Context, userID uuid.UUID) ([]*models.AppSpecificPassword, error)
        Revoke(ctx context.Context, id, userID uuid.UUID) error
        FindActiveByUser(ctx context.Context, userID uuid.UUID) ([]*models.AppSpecificPassword, error)
        UpdateLastUsed(ctx context.Context, id uuid.UUID) error
    }
    ```

    **PostgreSQL implementation** in `backend/internal/caldav/postgres_app_password.go`:
    - Implement all repository methods using pgx pool
    - `FindActiveByUser` returns passwords WHERE revoked_at IS NULL for the given user
    - `Revoke` sets revoked_at = NOW() WHERE id = $1 AND user_id = $2
    - `UpdateLastUsed` sets last_used_at = NOW()

    **App-specific password service** in `backend/internal/caldav/app_password.go`:
    ```go
    type AppPasswordService struct {
        repo AppPasswordRepository
        pool *pgxpool.Pool  // for settings queries
    }
    ```

    Methods:
    - `Create(ctx, userID, label) (password string, pw *models.AppSpecificPassword, error)`: Generate 32-byte random password (hex encoded = 64 chars), bcrypt hash with cost 12, store with first 4 chars as prefix. Return plaintext password (shown once to user).
    - `Validate(ctx, username, password) (uuid.UUID, error)`: username = user email or user ID. Look up active passwords for the user, bcrypt.CompareHashAndPassword each until match. Return user_id. Update last_used_at on success. Check global org toggle first -- if disabled, return ErrCalDAVDisabled.
    - `List(ctx, userID) ([]*models.AppSpecificPassword, error)`: Return all (including revoked) for display.
    - `Revoke(ctx, id, userID) error`: Revoke specific password.
    - `IsOrgEnabled(ctx) (bool, error)`: Query caldav_settings for 'caldav_carddav_enabled'.
    - `SetOrgEnabled(ctx, enabled bool) error`: Upsert caldav_settings.

    Note: username for Validate can be user email (resolve via auth gRPC) or user UUID string (direct match). For simplicity in v1, use user UUID as the username -- shown to user in setup wizard. The password lookup iterates active passwords for that user_id and compares with bcrypt. This avoids needing to resolve emails.

    **Sync token service** in `backend/internal/caldav/sync_token.go`:
    ```go
    type SyncTokenService struct {
        pool *pgxpool.Pool
    }
    ```

    Methods:
    - `GetSyncToken(ctx, collectionType, collectionID) (string, error)`: Get current sync_version from caldav_sync_versions (INSERT 0 if missing via ON CONFLICT DO NOTHING), return as `"sync-token-{version}"` string.
    - `IncrementAndLog(ctx, collectionType, collectionID, objectPath, changeType) error`: Within a transaction: (1) INSERT INTO caldav_sync_versions ON CONFLICT DO UPDATE SET sync_version = sync_version + 1, (2) INSERT change_log entry with the new sync_version.
    - `GetChangesSince(ctx, collectionType, collectionID, sinceVersion) ([]models.CalDAVChangeLogEntry, string, error)`: Query change_log WHERE sync_version > sinceVersion, return entries + current token.
    - `ParseSyncToken(token string) (int64, error)`: Extract version number from "sync-token-{N}" format.

    Follow existing codebase conventions: structured slog logging, errors.New for sentinels, pgx $N placeholders, context.Context as first param.
