    **CalDAV/CardDAV routes** in `backend/internal/gateway/route_caldav.go`:

    Create a `CalDAVRoutes` struct (NOT implementing RouteRegistrar -- like WOPIRoutes, these use their own auth, not JWT):

    ```go
    type CalDAVRoutes struct {
        caldavHandler  http.Handler  // caldav.Handler from go-webdav
        carddavHandler http.Handler  // carddav.Handler from go-webdav
        appPwService   *caldavpkg.AppPasswordService
        authMiddleware func(http.Handler) http.Handler  // standard JWT auth for API endpoints
    }

    func NewCalDAVRoutes(
        caldavHandler http.Handler,
        carddavHandler http.Handler,
        appPwService *caldavpkg.AppPasswordService,
        authMiddleware func(http.Handler) http.Handler,
    ) *CalDAVRoutes
    ```

    **Basic Auth middleware** (inside route_caldav.go):
    ```go
    func (c *CalDAVRoutes) basicAuthMiddleware() func(http.Handler) http.Handler
    ```
    - Extract Basic Auth credentials via `r.BasicAuth()`
    - If no credentials: respond 401 with `WWW-Authenticate: Basic realm="KMU Hub CalDAV"`
    - Call `appPwService.Validate(ctx, username, password)` -- returns userID
    - On success: inject userID into context via `caldavpkg.CtxWithUser(ctx, userID)`
    - On failure: respond 401

    **RegisterRoutes method** (called directly from main.go, not via registrar loop):
    ```go
    func (c *CalDAVRoutes) RegisterRoutes(r chi.Router)
    ```

    Register these route groups:

    1. `.well-known` auto-discovery (no auth):
       - `GET /.well-known/caldav` -> 301 redirect to `/caldav/`
       - `GET /.well-known/carddav` -> 301 redirect to `/carddav/`

    2. CalDAV protocol routes (Basic Auth):
       - Mount `/caldav/` with basicAuthMiddleware wrapping caldavHandler
       - The go-webdav caldav.Handler handles all PROPFIND, REPORT, GET, PUT, DELETE, MKCALENDAR methods internally

    3. CardDAV protocol routes (Basic Auth):
       - Mount `/carddav/` with basicAuthMiddleware wrapping carddavHandler

    4. App-specific password API endpoints (standard JWT auth, under `/api/v1/caldav/`):
       - `GET /api/v1/caldav/passwords` -- List user's app-specific passwords (label, prefix, last_used, created_at, revoked_at). Never return password_hash.
       - `POST /api/v1/caldav/passwords` -- Create new app-specific password. Request body: `{label: string}`. Response: `{password: string, id: string, label: string, prefix: string}`. The plaintext password is shown ONCE.
       - `DELETE /api/v1/caldav/passwords/{id}` -- Revoke an app-specific password.
       - `GET /api/v1/caldav/status` -- Get CalDAV/CardDAV status for current user (org enabled, user caldav_enabled, password count).
       - `PUT /api/v1/caldav/enable` -- Enable CalDAV for current user (sets users.caldav_enabled = true).
       - `PUT /api/v1/caldav/disable` -- Disable CalDAV for current user.

    5. Admin API endpoints (JWT auth + admin role):
       - `GET /api/v1/admin/caldav/settings` -- Get org-wide CalDAV/CardDAV enabled status.
       - `PUT /api/v1/admin/caldav/settings` -- Set org-wide CalDAV/CardDAV enabled/disabled. Request: `{enabled: bool}`.
       - `GET /api/v1/admin/caldav/users` -- List users with CalDAV enabled (for audit). Query caldav_enabled users with password count.
       - `DELETE /api/v1/admin/caldav/users/{userId}/passwords` -- Admin revokes all passwords for a user.

    **Gateway main.go wiring:**

    After the WOPI routes block, add CalDAV/CardDAV setup:

    ```go
    // CalDAV/CardDAV protocol routes (Basic Auth, not JWT)
    caldavSyncService := caldavpkg.NewSyncTokenService(pool)
    caldavAppPwService := caldavpkg.NewAppPasswordService(
        caldavpkg.NewPostgresAppPasswordRepository(pool), pool,
    )
    caldavBackend := caldavpkg.NewCalDAVBackend(registry, caldavSyncService, pool)
    carddavBackend := caldavpkg.NewCardDAVBackend(registry, caldavSyncService, pool)

    caldavHandler := &caldav.Handler{Backend: caldavBackend, Prefix: "/caldav"}
    carddavHandler := &carddav.Handler{Backend: carddavBackend, Prefix: "/carddav"}

    caldavRoutes := gateway.NewCalDAVRoutes(caldavHandler, carddavHandler, caldavAppPwService, authMiddleware)
    caldavRoutes.RegisterRoutes(r)
    slog.Info("routes registered", "service", "caldav")
    ```

    Import the caldav package: `caldavpkg "github.com/kmuhub/kmuhub/internal/caldav"` and go-webdav packages: `"github.com/emersion/go-webdav/caldav"`, `"github.com/emersion/go-webdav/carddav"`.

    Use existing response helpers from `backend/internal/server/response/` for JSON API endpoints. Follow the WOPI pattern for protocol routes (root-level, outside registrar loop, custom auth).
