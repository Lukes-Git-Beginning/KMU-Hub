<objective>
Add server-side storage for dashboard layouts with role-based defaults (DESK-03). Admin can configure what CEO/manager/member dashboards look like by default, and user customizations are persisted to the server.

Purpose: This fulfills the role-based dashboard requirement. Without server-side storage, layouts only live in localStorage and are lost on device changes. Admin-configurable defaults ensure each role gets an appropriate initial workspace.

Output: Backend migration + endpoints for dashboard layouts, admin settings page for role defaults, and dashboard store synced to server.
</objective>
