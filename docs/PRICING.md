## KMU Hub Pricing-Modell

### Einmalkosten

| Posten | Preis |
|--------|-------|
| Onsite-Prozessanalyse (1 Woche) | 5.000-8.000 EUR |
| Initiales Setup & Konfiguration | Inkludiert |
| Datenmigration (aus Alt-System) | 1.000-3.000 EUR (optional) |
| Custom WASM-Plugins (pro Plugin) | 2.000-10.000 EUR (optional) |

### Monatliche Kosten (SaaS)

| Option | Preis |

## Differenzierung

1. **Onsite-Prozessanalyse** — kein anderer CRM-Anbieter macht das
2. **EU-Datensouveraenitaet** — Self-Hosted Option, EU-only Hosting
3. **Faire Preise** — deutlich unter Salesforce/HubSpot Enterprise
4. **Keine Vendor-Lock-In** — Self-Hosted + Datenexport jederzeit
5. **All-in-One** — CRM + Chat + Video in einem Tool (kein Slack + Salesforce + Zoom)

## Revenue-Ziel (Jahr 1 nach Launch)

- 20 Kunden x durchschnittlich 15 User x 39 EUR = 11.700 EUR/Monat
- + 10 Onsite-Analysen x 6.500 EUR = 65.000 EUR
- + 5 Self-Hosted Lizenzen x 5.000 EUR = 25.000 EUR
- **Ziel Jahr 1: ~230.000 EUR**
